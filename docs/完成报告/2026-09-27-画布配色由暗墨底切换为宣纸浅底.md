1. **`js/entities/enemy/rendering.js`** —— 敌人四种状态色全部由浅灰改为墨色系，否则状态反馈在浅底上完全消失：

   - 减速 `#b0b0b0` → `#6a6459`（淡墨）

2. **射程指示圈** —— 4 处 `rgba(255,255,0,...)`（黄）改为 `rgba(176,58,46,...)`（朱砂）：
   `js/entities/towers/rendering-basic.js`、`js/entities/towers/fusion.js`、`js/ui/input.js`、`js/modes/conquest/rendering.js`
3. **`js/inkRenderer.js`** —— `drawInkText` 的墨晕 `rgba(0,0,0,0.3)` → `rgba(28,26,23,0.22)`；飞白高光 `rgba(255,255,255,0.2)` → `rgba(28,26,23,0.14)`（白色高光在浅纸上无效且会冲淡墨色）

## 3. 关键实现说明

- 底色由 `js/runtime.js` 的 `StaticCanvasLayer` 用 `CONFIG.COLORS.bg` 满幅填充，因此改常量即生效，无需改渲染逻辑。
- 敌人与文字均走 `InkRenderer.drawInkText`，敌人显式传入 `CONFIG.COLORS.enemy`，故改常量即可；未显式传色的调用继承新的默认色 `#1c1a17`。
- 网格由 `Game.drawGrid` 用 `CONFIG.COLORS.grid` 描边，静态层绘制，改常量即生效。

## 5. 未解决问题（重要）

### 5.1 炮塔字形对比度风险 —— 受硬约束本次未修

底色变为 `#f4efe4` 后，深底专用的浅色塔字会失去对比度，实测对比最弱的几项：

| 元素 | 色值 | 在 `#f4efe4` 上 |
|---|---|---|
| 飞白塔字 `COLORS.tower` | `#e8e8e8` | 近乎不可见 |
| 选中态 `COLORS.highlight` | `#d4d4d4` | 近乎不可见 |
| 冰塔 `ice` | `#80d8ff` | 弱 |
| 毒塔 `poison` | `#76ff03` | 弱 |
| 金/灯 `treasure` `#ffd700`、`lantern` `#ffe082` | 亮黄 | 弱 |
| 木塔 `#90b090` | 浅绿灰 | 弱 |

**这是当前画面的主要可读性问题**，且源于「炮塔字体颜色不修改」这一硬约束。若后续放开该约束，建议将塔字统一改为深墨 `#1c1a17`，元素差异改用**色相中的深色版本**或**笔画特效**表达，而非亮色。

### 5.2 UI 外壳未同步

`css/style/*.css` 与 `css/inline/*.css`（合计约 4100 行）的页面背景仍为 `#0c0c0c`，文字为 `#f5f5f5`。画布变浅后与外壳存在明暗割裂（表现为「浅色画布嵌在深色页面中」）。本次范围限定为画布，外壳作为独立工单处理。

### 5.3 路径色调偏重

`COLORS.path #2d2d2d` 与 `pathLine #3a3a3a` 在浅底上呈现为近黑的宽色带（`lineWidth = CELL_SIZE - 4 = 44px`），与宣纸调性不符。原型 `04-墨为血` 中路径为 `rgba(28,26,23,0.10)` 的极淡宽线。未改，待确认。
