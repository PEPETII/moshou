## 实际完成内容

1. **图鉴主界面**：改用 `.ink-page` 三段骨架。「‹ 主菜单」固定在顶栏左上，右侧显示收录总数；两张入口卡占满内容区，卡上带朱印标签「已录 2 字」「已录 3 种」。旧版返回按钮被裁到可视区外的问题（K1）已经消失。
2. **炮塔志 / 妖异录**：改为常驻双栏（40 : 60），删除抽屉式详情和「关闭」按钮。进入时**默认选中第一项**，选中项有朱砂竖印；支持上下方向键切换（`role="listbox"`）。左栏底部加了一行淡墨引导「轻点字目 · 观其笔意」。
3. **富列表项**：印块（火为朱红，水为青灰）、名称、一句定位、造价或血量标签。
4. **炮塔详情**：米字格上**按笔顺逐笔写出「火」「水」**。正在写的笔为元素色，写完的笔回到墨色，下方笔顺名同步高亮；点击可以重写；开启减少动效时直接显示整字。右侧是射程、造价、笔画数；下方是普攻和大招两张招式卡。
5. **妖异详情**：生命（血）、移速（格/秒，加「迅 / 常 / 缓」分档）、撞核伤害、击败奖励，以及一段描述。
6. **导航**：顶栏左上为「‹ 图鉴」，右侧「主菜单」直接返回主菜单（K3）。
7. **清理**：删除过时的筛选页签和 `getTowerCategory`（B1）；页内标题统一为「炮塔志」「妖异录」（B2）；删除三处旧图鉴样式。

## 关键实现

- 三个页面容器**保留原 ID**，`menu.js`、`conquest.js` 中统一隐藏面板的逻辑无需改动。
- 书写预览直接复用战斗中的 `Brush.drawStroke`（支持 `progress` 参数），笔画数据只有 `CONFIG.GLYPHS` 一份；米字格由 CSS 背景绘制，画布只画笔画；画布按设备像素比放大。离开页面时 `CodexGlyph.stop()` 取消动画帧。
- 图鉴文案集中在 `CONFIG.CODEX`，只写配置中能核实的事实（例如巨的撞核伤害 3，是尸、鬼的 3 倍）。
