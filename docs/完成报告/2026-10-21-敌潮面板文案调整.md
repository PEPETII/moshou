# 敌潮面板文案调整 完成报告

对应工单：[docs/工单计划/2026-10-21-敌潮面板文案调整.md](../工单计划/2026-10-21-敌潮面板文案调整.md)

## 实际完成内容

1. 敌潮选择弹窗标题「择潮」→「敌潮」。
2. 删除三档选项中的两行数值文案：`每秒 X 只`、`巨 每 Y 秒`。选项现在只保留大字名称（稀 / 常 / 潮）与一句风格描述。
3. 选项内部改为纵向居中并加大内边距，删行后面板从原来的四行卡片收紧为两行卡片，视觉重心未塌陷。

## 修改文件

| 文件 | 改动 |
| --- | --- |
| `js/ui/density-picker.js` | 标题文案改「敌潮」；`btn.innerHTML` 去掉 `density-rate`、`density-giant` 两个 span |
| `css/ink-ui/battle.css` | 删除 `.density-rate` / `.density-giant` 规则；`.density-option` 增 `justify-content: center`、`gap` 6px、`padding` 14px 6px；矮横屏下 padding 6px → 8px |

未改动 `CONFIG.DENSITY` 的 `rate`、`giantEvery`，刷怪节奏与三档数值无任何变化；`DENSITY_DEFAULT`（潮）、键盘 1/2/3 快选、`aria-pressed` 高亮逻辑均保持原样。

## 关键实现

```js
btn.innerHTML =
  `<span class="density-label">${cfg.label}</span>` +
  `<span class="density-desc">${cfg.desc}</span>`;
```

选项容器由 `flex-start` 改为 `justify-content: center`，卡片高度由内容决定（实测 69px），三卡仍 `flex: 1 1 0` 等宽。
