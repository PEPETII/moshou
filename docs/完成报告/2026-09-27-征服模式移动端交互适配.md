## 3. 关键实现

1. **单指状态机**（`touch.js`）：`touchstart` 记录 `origin / cell / tower(容差) / moved / dragging` 并起预览；
   `touchmove` 持续更新落点格、按 `slop=12px` 判定进入拖拽；
   `touchend` 三分支——拖拽（融合 → 移动 → 原因提示）、滑动取消（融合塔另给提示）、干净轻点（点塔看信息 / 点空白关闭）。
2. **容差语义与塔防模式一致**：拾取/融合用 `DeviceProfile.tapTolerance`（0.75 格）；移动取抬起点（不消耗资源，"拖到哪放哪"），失败必给原因。
3. **反馈通道复用**：`_notify()` 走 `window.gameInstance.ui.showToast`，没有 UI 实例时降级 `console.warn`，不新增第二套 toast UI。
4. **桌面端零回归**：鼠标链路（`mousedown/mousemove/mouseup/contextmenu`）原样保留；触摸监听仅在 `hasTouch` 时注册；`_dragSource` 只在触摸链写入，幽灵塔上移对鼠标无效。
