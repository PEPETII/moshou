# 水墨主题音效系统补全

## 实际完成内容

- 新增 `js/audio.js`，通过 Web Audio API 合成落笔、笔锋、墨散、印章、波鼓和纸裂六类短音效，无外部音频文件或网络依赖。
- 普通模式与征服模式的操作区均新增音效开关；两个控件共用状态，使用 `aria-pressed` 表示状态，并在浏览器本地存储可用时跨刷新保存。
- 将音效接入成功的放塔/召唤、塔攻击、敌人击杀、炮塔融合、波次开始和核心受击路径。对攻击、击杀、核心受击等高频事件做了节流。
- 无 Web Audio 支持时禁用开关并跳过播放；音频节点异常不会中断游戏逻辑。
- 更新 README 的音效说明和脚本依赖图，建立本工单。

## 关键实现

- 音频上下文按需创建；波次、放置等用户操作可解锁上下文，页面载入时不会自动播放。
- 主输出节点可整体静音/恢复，开关状态保存在 `moshou-sound-enabled`。
- 攻击、击杀、融合、波次和核心受击有独立节流窗口，减少密集触发时的音量堆叠。
- 两种模式使用不同 DOM 控件但共享一个 `InkAudio` 状态，页面中仅保留一个 `sound-toggle` ID。
