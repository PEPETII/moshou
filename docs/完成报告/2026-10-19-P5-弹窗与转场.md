## 实际完成内容

1. **卷轴面板与遮罩**：在 `components.css` 新增 `.ink-scroll`（一层纸面、上下两根两端渐隐的墨杆、柔和投影）和 `.ink-veil`（统一的淡墨遮罩 `--veil-ink`，让开安全区）。胜负弹窗、择潮、暂停、战斗设置四种弹层全部套用，原来的「错位纸张」（`box-shadow: 8px 8px 0`）和上下粗细不一的实线都已去掉（C4）。
2. **`InkModal`**（`js/ui/ink-modal.js`）：塔防和征服的胜负、普通告知共用一个渲染函数。
   - 右上角是落印动画的大印（胜「成」、破为裂印「破」）。
   - 大字「胜 / 破」带入场缩放。
   - 星级显示为三枚朱印，亮暗对应星数，逐枚落印（B6）。
   - 按钮组：最右为朱红主按钮。

     | 情形 | 按钮 |
     |---|---|
     | 塔防胜，有下一关 | 重来 / 选关 / **下一关** |
     | 塔防胜，末关 | 重来 / 主菜单 / **选关** |
     | 塔防败 | 主菜单 / 选关 / **重来** |
     | 征服胜 | 重来 / 选关 / **下一关**（末关时为 重来 / **选关**） |
     | 征服败 | 选关 / **重来** |

   - 征服原来的两套实现（`showModal`、`showVictoryModalWithNextLevel` 临时创建按钮）合并为一套；`UI.showModal` 和 `ConquestGame.showModal` 保留原签名，内部改为转调 `InkModal`。
   - 胜负音效仍由 `InkUI.setModalScene` 触发。
3. **暂停菜单**按钮改为组件：「继续」为主按钮，「设置」为次按钮，「返回主菜单」为幽按钮。
4. **墨晕转场**（C5）：`page-transition.js` 记录最近一次按下的位置，写入 `--tap-x/--tap-y`。所有 `.ink-page` 页面和主菜单首页出现时，以该点为圆心用 `clip-path` 晕开（280ms）；弹层面板以「卷轴展开」方式出现，遮罩淡入。开启减少动效时全部关闭。
5. **触屏不自动聚焦**：胜负弹窗和择潮在触屏上不再自动聚焦主按钮，避免主按钮外再套一圈焦点框；键盘和鼠标环境仍会聚焦。
