## 关键实现

- 货币状态键/属性：`game.gold` → `game.ink`；配置 `startGold`→`startInk`、`goldPerWave`→`inkPerWave`、`goldPerWaveInc`→`inkPerWaveInc`；提示码 `insufficient_gold`→`insufficient_ink`；DOM id `gold`→`ink`、`conquest-gold`→`conquest-ink`（含 CSS 选择器 `#gold`/`#conquest-gold`）。
- 受保护项（未改动）：金行塔元素 `type:'gold'`、融合配方 `gold+*`、塔卡 `data-type="gold"`、`char:"金"`、颜色键 `gold:'#a67c00'`、图鉴/渲染中的 `case 'gold'`、塔与敌人的类型判断。
- 数值格式保持不变：整数、无千分位（与原文案一致）；单位由「金」改为「墨」，如 `120墨`、`+X墨`、`奖励: X墨`。
