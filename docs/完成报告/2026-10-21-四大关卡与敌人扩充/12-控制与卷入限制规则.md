# 12 控制与卷入限制规则：完成报告

工单：[12-控制与卷入限制规则](../../工单计划/2026-10-21-四大关卡与敌人扩充/12-控制与卷入限制规则.md)

## 实际完成内容

- 配置（`js/config/control-rules.js`）：`CONTROL.tiers` 五档（小怪/重敌/双字/三字/四字）× 八个字段（`carry`、`carryCost`、`carryDistMul`、`pull`、`pullMul`、`knockMul`、`ccMul`、`freezeToSlow`、`slowCap`、`diminish`），`carryBudget`（水 14、风 10）、`carryImmune` 3 秒、`pullImmune` 2 秒、硬控递减窗口（6 秒、100%/50%/25%、第 4 次免疫 2 秒）、`ccMaxSingle` 2.5 秒、震慑（每秒 30 点、满 100 踉跄 1.2 秒、之后 8 秒不累积、踉跄时速度 × 0.4）、`ampCap` 1.8、`suppressFloor`。
- 运行时接口（`js/glyph/control-rules.js` 的 `ControlRules`）：`tier / canCarry / carryCost / knock / stun / freeze / root / slow / slowCapOf / amp / addStagger / tick`。所有塔的控制效果都改调这里；`Enemy.knockback / glyphStun / freeze / glyphSlow` 保留为经规则的便捷入口，真正的底层原语是 `knockbackRaw / stunRaw / glyphSlowRaw`。
- 水·潮：每道浪 14 点体量预算，按里程从大到小（离核心近的优先）；预算不够、三字、四字、刚被放下的敌人只吃伤害并被打湿；倒卷距离按档位打折（重敌 × 0.5、双字 × 0.35）；放下后 3 秒内不能再被卷。
- 风·旋：每个旋风最多吸 10 点体量、先来后到、一只敌人只被一个旋风吸（`pulledBy`）、吸力按档位打折、离开后 2 秒吸力 × 0.3、三字四字不吸入；覆盖到瘴时标记瘴雾消散。
- 外部增伤叠乘上限：破甲 × 湿身（雷的 `wetBonus`）合计 ≤ 1.8，塔自身的暴击/重敌加成不计；雷塔不再自己乘 `wetMul`，改传 `wetBonus`。
- 旧 `GLYPH_STATUS.giantKnockMul` 已删除，重敌判定改看 `tier`。
- 12 §3.8 的数值配套（冰 1.6、水潮 10/22）在 11 号报告里。

## 关键实现

- 硬控入口 `hardControl`：免疫控制 → 空中且来自地面效果则忽略 → 三字冻结转减速 → 首领转震慑 → 档位 `ccMul` → 镇压光环（只对小怪）→ 递减（只对非小怪）→ 单次上限 → 写入 `stun`（冻结另记 `iceTime`）。
- 震慑锁定：踉跄结束后 `staggerLock` 秒内 `addStagger` 直接返回。
- 水·潮的伤害对不能卷入的敌人依然生效（`waveCatchDamage` 10、`waveEndDamage` 22）。

## 测试 / 验证结果

`npm run test:control`（51 项）：分档表每一格；击退/硬控/减速上限按档位；递减（双字连续 4 次、小怪不递减）；首领震慑累积、踉跄、8 秒锁定、击退不累积、踉跄速度 × 0.4；增伤 ≤ 1.8；一道潮卷入体量 ≤ 14；四字、三字不被卷但吃伤害；**4 座水塔轮流放潮，任何敌人 10 秒内累计被卷入 ≤ 4 秒**；风旋预算 ≤ 10、一敌一风、三字四字不吸、结束释放与抗性；静态检查 `js/glyph/` 下不再直接调用 `glyphStun / freeze / knockback / glyphSlow`。
