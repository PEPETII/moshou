# 07 敌人框架：能力组件与多字分段：完成报告

工单：[07-敌人框架-能力与多字](../../工单计划/2026-10-21-四大关卡与敌人扩充/07-敌人框架-能力与多字.md)

## 实际完成内容

- 配置格式：`tier`（minor/heavy/elite/greater/boss）、`abilities`、`segments`（每字 `char`、`hp`、`abilities`）；多字敌人总血量由各段相加（`glyph-battle.js` 的换算循环里推导）；派生字段 `glyphCount`、`mass`、`isBoss`、`segIndex`、`segs[]`。
- 能力框架（`js/entities/enemy/abilities/registry.js`）：`init / update / onHit / onLethal / onSegmentBreak / draw / onControlled / onExpose` 钩子；碎字失效（挂在第 i 个字的能力只在 `segIndex ≤ i` 时生效）；能力冻结（被卷、眩晕时不触发主动效果，冷却到 0 后等待）；冷却统一 `dt × abilityTimeScale`，不用 `Date.now()`。
- 伤害管线（`segments.js`）：能力 `onHit` → 光环类减伤 → 外部增伤（受 `ampCap` 约束）→ 扣在当前段 → 溢出顺延；碎字特效（碎墨、飘字、轻震屏，首领另有顿帧与重震屏）；全部碎完走 `onLethal`，任一能力返回 true 就不死（复聚、复生的「假死」不计击杀、不给奖励）。
- 不可选中（`untargetable`）与显形：单体选目标统一过滤（`GlyphKit.targetable` / `best` / `touch`、`GlyphTower.frontTarget`、火星追踪的 `nearestEnemy(..., true)`）；范围效果（`aoe: true`）命中后显形 1.5 秒；不可选中时画成 35% 透明度虚影。
- 召唤接口：`EnemyAbilities.summon` 在召唤者后方 10～40px 出生、同一路径、遵守 `ENEMY_CAP`；`spawnGlyphEnemy(type, { pathIndex, s, summoned })`；召唤物奖励固定 1 墨。
- 多字绘制：逐字沿路径从前往后排列（字间距 0.9 倍字号）、碎字后剩余字 0.3 秒合拢、分段血条只在血量变化后 2 秒内显示、首领不画头顶血条；范围查询的包围盒按字数放大。
- 妖异录：23 条，每条有 `role` / `desc` / `traits`；卡片显示字数徽记（单/双/三/四），首领卡朱砂边框；多字敌人在详情页并排显示各字。
- 新敌人初见提示（14 §2.1）：第一次遇到某种新敌人时画布下方弹小卡片，3 秒淡出，记在 `localStorage.moshou_enemy_seen`，设置里「敌人提示」开关（默认开）。

## 关键实现

- 尸、鬼、巨的 `adv === false`，仍走旧 `takeDamage`，行为与数值不变（`test:glyph`、`test:damage` 通过）。
- 光环类状态（傀儡加速、瘴雾、镇压、筑墙、治疗锁定）的计时放在 `Enemy.tickTimers`，对**所有**敌人生效（尸、鬼、巨也会被傀儡加速、被瘴雾保护），不依赖它们自己有没有能力。
- 空中（蛙、鬼浮）通过 `airborne` 标志，`Enemy.hit` 直接忽略 `delivery: 'ground'` 的伤害，`ControlRules.slow/stun(…, 'ground')` 也不生效。

## 测试 / 验证结果

- `npm run test:segments`（37 项）：三字敌人恰好第一段血量的伤害 → 第一段碎、第二段满血；溢出一次打碎两段；能力随字失效；被卷、眩晕不触发主动能力；不可选中/显形 1.5 秒/夜字碎后永久显形；召唤出生位置、奖励、ENEMY_CAP；白骨精骨字复原（4 秒、50%、只一次、火打碎不复原、4 秒内打碎精字则不复原）；镇墓兽开墓；尸鬼巨旧路径。
- `test:damage`、`test:frame`、`test:glyph` 回归通过。

## 未解决问题
