# 完成报告：修复手机端自定义子界面返回按钮不可见

## 实际完成内容
修复了手机（横屏矮视口）下进入「自定义」的三个子界面（自定义炮塔 / 自定义关卡 / 导出/导入）后返回按钮被裁切出屏、用户无法返回的问题。

## 原因分析
- 返回按钮在 DOM 中一直存在（js/bootstrap/page-markup.js），并非缺失。
- `#main-menu` 为 `position:fixed; height:100%` 的 flex 居中容器且不可滚动；矮视口下子界面内容总高超出视口，`justify-content:center` 使上下两端同时被裁切，返回按钮落到可视区之外且无法滚动。

## 修改文件
- css/style/part-04.css：新增 `@media (max-height: 500px) and (orientation: landscape)` 移动端媒体查询，压缩 `.custom-sub-title` / `.custom-sub-header` / `.custom-placeholder` 及返回按钮的尺寸与间距，占位卡片宽度改为 `min(90vw, 480px)`，并给 `#main-menu` 加 `overflow-y: auto` 兜底。

## 测试/验证结果
使用 Playwright + 系统 Edge 以 844×390（手机横屏）视口实测：
- 依次进入自定义炮塔、自定义关卡、导出/导入三个子界面；
- 三个返回按钮 `getBoundingClientRect()` 均完整在视口内（bottom≈319 < 390），截图确认可见，点击返回正常。

## 未解决问题
无。

## 后续建议
- 三个自定义子界面仍是占位页，功能实现时注意沿用响应式样式。
- 其他菜单类界面（如图鉴层级）如有类似矮视口溢出问题，可参考本次的媒体查询方案。
