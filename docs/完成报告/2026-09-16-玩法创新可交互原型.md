## 关键实现

### 1. 统一视觉体系
所有页面共用一套内联设计令牌，对齐游戏既有的水墨美术方向：白纸底 `#f4efe4` + 纸面底 `#e7e1d2`、墨黑 `#1c1a17`、朱砂红 `#b03a2e`、格线 `#ded5c0`；字体走楷体族（`Kaiti SC / KaiTi / STKaiti`）；汉字一律通过 `shadowBlur` 加墨晕。

### 2. 每个方案的"演示核心"各不相同
原型不是把同一套代码换皮，而是各自实现了该方案最关键的那一步机制：

- **01 字格营造**：采用「逐格部件」渲染而非把字拉伸铺满——`林` 由两格 `木` 并置、`炎` 由两格 `火` 上下叠、`囚` 由 `囗` 框住 `人`、`鑫` 由三格 `金` 组成。这样"结构即拓扑"是**看得见**的，而不是靠文字解释。
- **02 句读改径**：实现了标点的方向敏感性——`、` 生成分流克隆、`。` 令敌人掉头从左侧离场（"被读掉"）、`？` 冻结、`！` 加速并自伤。**标点只在顺读方向生效**，避免折返敌人反复触发已越过的标点导致连锁失控。
- **03 语法羁绊**：实现了三层结构。层一为单字；层二用 `grammar()` 按偏正（修饰字 + 中心字）/ 动宾（两个不同攻击字）/ 并列（同字）判定，**两个修饰字不组词**（语法在限制布局，不只是奖励）；层三扫描横竖直线上的连续塔来触发句法技。悬停时会预览即将生成的词。
- **04 墨为血**：用离屏 canvas + `destination-out` 按预设色带擦除笔画，实现"缺笔降级"的视觉效果；字随笔画数走退化链（`火`→`人`）；浓墨字向邻格晕染会降低邻字浓度。
- **05 对句波次**：实现了确定性的对仗判定——按位置比对"词性"与"意象"两个维度各计 1 分，满分 10。**刻意不做平仄判定**，因为机器判平仄会让游戏变成语文考试。
- **06 错别字入侵**：改写表刻意选用**形近字**而非任意换字（火→灭、木→术、土→士、水→冰），因为"字形相近、意义全变"恰好就是中文错别字的本质，玩家一眼能看出"这个字不对"。

### 3. 首屏即有效果
三个偏"放置"的方案（01／03／06）在加载时就预置了内容，避免空画布：
- 01 预置四种结构各一，四种效果可横向对比；
- 03 预置 `山火水` 一行 + `金金` 一对，一次性展示偏正、动宾、并列、句法技四层全部生效；
- 06 预置三塔紧贴路径，加载后即可看到敌人前来改字。

### 期间修正的两个自查问题
1. **方案六触发距离过紧**：初版敌人改写判定阈值为 `CELL × 0.8`，而相邻格中心距恒为 `CELL`，导致默认塔永远不会被改写、核心机制在演示中不出现。已改为 `CELL × 1.3` 并重排默认塔位（`(7,4)`、`(12,4)`、`(12,7)`，均距路径 48px）。
2. **方案一标签越界**：字形标签固定画在字形上方，位于首行的字形会把标签顶出画布。已改为按 `y0 >= 24` 判断，空间不足时翻到字形下方，并改为在占格范围内居中。

## 未解决问题

1. **未做浏览器渲染校验**。原本计划用 Playwright 截图逐页核对视觉，但 Chromium 安装被取消，无法进行像素级验证。当前的校验只覆盖到"脚本能编译 + 无外部依赖 + 行数达标"，**不覆盖运行时 DOM 行为与视觉效果**。建议首次打开时留意各页控制台。
2. **方案二未实现真正的图寻路**。原型用的是"沿单行字序 + 标点修饰行为"的简化模型，而完整方案需要把静态 `path` 数组改成动态字序图寻路。原型足以验证玩家是否理解并接受这个机制，但不能代表最终工程量。
3. **方案五的词库是硬编码的 19 个字**。仅够演示判定逻辑，真实内容量需要策划表维护意象词库与可对项，工作量与关卡设计深度绑定。
4. **原型数值非平衡数值**。伤害、冷却、耗墨量只为让效果可见，未经任何平衡测算。

## 后续建议

1. **按 P0 → P3 顺序阅读**：先看 `03-语法羁绊.html`（唯一四项评分全 ≥4.0、依赖最少），再看 `04`、`01`。这三个叠加起来才是完整的新核心循环。
2. **用方案三的最小原型做决策**：在现有地图上不新增任何塔，只落地"层二·词"，观察玩家是否**主动**为凑词去调整布局。若是，则"文字即规则"的核心假设成立，可推进 P1——这个判断成本最低、信息量最高，不需要新美术、新敌人、新资源。
3. **把高风险的三个方案隔离在独立模式**：项目已有 `js/modes/conquest/` 的独立模式架构，方案五、六适合直接复用该骨架，把风险与主线解耦。
4. **真要做像素级校验时**，可重新执行 `npx playwright install chromium`，再写一个脚本批量截图对比。
