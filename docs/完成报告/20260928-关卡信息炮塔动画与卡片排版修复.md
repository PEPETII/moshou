## 关键实现

- `requestAnimationFrame` 更新调用中的时间戳沿炮塔攻击触发路径传递给 `triggerAttackAnimation(timestamp)`；基础塔与融合塔的 `draw` 都调用 `getAttackAnimationProgress(timestamp)`，避免 `performance.now()` 与 `Date.now()` 混算，也避免进度越界。
- 原先按 200ms 攻击动画进度运行多个正弦周期的位移，改为单次平滑脉冲并缩小位移；没有添加逐帧随机偏移。
- `createTowerSelects()` 仍使用原来的“前两个字 + 剩余字符”结构，仅为三字及以上卡片附加 `multi-character` 类。通用 CSS 将两段内容纵向排列，字号 16px、行高 1.05、字距 1px；价格节点及卡片尺寸未改变。
- 移动端关卡按钮改在第二行显示，桌面端与编号、名称同处一行。
