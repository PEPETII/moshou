# 完成报告：塔卡栏左置 + 拐角平滑

## 实际完成内容
- 塔防塔卡栏移到画布左缘，一行一张（字 + 墨价横排），纵向滚动；右缘保留「停」与战况（守/墨/时间/尸）。
- 镜头左右两侧都按 `BATTLE_DOCK_W` 留滚动余量，被遮挡的格子可滚出。
- 敌人路径拐角改为圆弧（二次贝塞尔，切线长 = `CONFIG.PATH_CORNER_RATIO` × 格长），朝向与车道偏移逐段渐变，不再在拐点瞬跳叠团。
- 地图墨廊与敌人轨迹同源倒圆角，路面与行走一致。征服模式（环形路径）同样受益。

## 关键实现
- `PathTrack._roundCorners` 把拐点替换为 8 段折线近似的圆弧；`cellS` 取格心在新轨迹上的最近里程并保持单调，山塔阻挡的 `cellIndexAt` 不变。
- `fromCells(cells, { round: false })` 可关闭圆角（测试用直角基线）。
- 卡片拖出放塔的手势按纵轴判定，向右拖即放塔，无需改动。

## 测试/验证结果
- `npm test` 全部通过（含行数检查）；新增圆弧朝向连续、cellS 单调的断言，拐角位置断言改为圆弧口径。
- 浏览器实测塔防第 2 关：卡片在左单列、右侧战况正常，拐角为圆弧。
