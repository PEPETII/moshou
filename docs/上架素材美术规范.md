# 《墨守成规》上架素材美术规范

适用于宣传图、壁纸、封面、Logo、宣传片标题卡等所有非实机素材。实机截图与录屏不做后期调色，只靠选关、布阵、取景来控制观感。

## 1. 视觉基调

**「宣纸上的一场书写之战」**：素纸上大面积留白，墨色分出远近，字就是兵也是妖，朱砂是唯一的强调色。

- 关键词：留白、洇墨、飞白、朱印、矿物色。
- 情绪：静中藏杀。远处是清淡的妖潮，近处焦墨写成的塔字锋芒毕露，两者之间留一段空白的"气口"。
- 取向：东方文人水墨，参照宋元山水的层层远山、明清写意的泼墨，加篆刻印章。**不做**国潮霓虹、仙侠 3D、金属描边、发光特效字。

## 2. 色彩

全部取自游戏运行时配置（`CONFIG.GLYPH_COLORS`、`mapBackground.js`），不新增色相。

| 角色 | 色值 | 用法 |
|---|---|---|
| 宣纸 | `#f4efe4` / `#f2ecdf` | 底色，占画面 45% 以上 |
| 焦墨 | `#1d1b18` | 标题、近景塔字、首领字 |
| 淡墨 | `#6b6458` | 中景敌群、路廊 |
| 清墨 | `rgba(30,27,22,.08~.2)` | 远山、雾 |
| 远山青灰 | `#8c9a98` 系 | 远层山与地图远景同源 |
| 朱砂 | `#b4473a`（印）/ `#c2412b`（火） | 印章、首领字的点睛、火塔；单幅面积不超过 8% |
| 塔色 | 火 `#c2412b`、水 `#2e5f80`、木 `#4f6f4a`、金 `#a8822a`、雷 `#5a4fa0`、冰 `#4f8fb0` 等 | 只出现在塔字和对应弹道上 |

规则：同屏彩色塔字最多 3 种。主塔用本色，其余塔用焦墨加本色晕。整体饱和度保持低，最鲜亮的地方留给火光和朱印。

## 3. 光影

水墨不画写实光源，"光"由纸白和晕染来表现：

- **纵深靠墨的浓淡**：近景是焦墨实笔加锐利边缘，中景是淡墨轻度晕开，远景是清墨大面积模糊并融进雾里。
- **高光靠留白**：塔字后方留出一团纸白的"气"，相当于逆光，让主体跳出画面。
- **暖光只来自火**：火、炎、焚的光晕取 `fireGlow` 一类颜色，用 `screen` 或低透明叠加，半径不超过字高的 1.5 倍。
- **暗角**：四周压一层茶渍色暗角（`rgba(120,96,60,.18)`），把视线收到中心。

## 4. 材质

| 材质 | 实现 |
|---|---|
| 宣纸 | 细纤维噪点、稀疏长纤维丝、低频茶渍斑，三层叠加，不出现可见的平铺纹理 |
| 洇墨 | 每个墨块先画一层模糊加扰动的晕边，再画实体，边缘不能是矢量硬边 |
| 飞白 | 笔画后段用纸色划出干笔丝（与游戏 `Brush.drawStroke` 同一算法） |
| 印泥 | 朱印用颗粒蒙版做出缺口与斑驳，印框要有轻微的手刻不平 |
| 泼墨 | 墨点要有主点、溅点、拖尾三级大小，按方向成簇出现，不均匀撒点 |

## 5. 造型与细节

- **塔字**：一律用游戏 `CONFIG.GLYPHS` 的笔画数据，经游戏自身的 `Brush` 渲染，保证与实机完全一致。不得用字体替代塔字。
- **敌人字**：取实机出现的敌人（尸、鬼、骨、狐、铠、夜叉、白骨精、四字首领等），用游戏同款书法字体，带拖影残墨。
- **弹道**：火星、水箭用 `Brush.drawTrail`，形态与实机招式一致。
- **标题**：「墨守成规」，马善政体（与主菜单同字体）。墨色带洇边与飞白颗粒，旁边配朱砂「守」字方印，与主菜单的标题加印章布局一致。
- **禁止出现**：游戏里没有的角色或兵器、写实人物、UI 卡片截图拼贴、除标题外的任何文字（含英文、宣传语、版本号）。

## 6. 构图

- 黄金分割与三分法：主体塔字落在右三分线，标题落在左三分区。
- 敌潮从远处的雾里沿墨廊路径蜿蜒而来，路径是全画面的引导线。
- 留白占画面 35% 以上；壁纸左侧 35% 是"公告 UI 安全区"，只放远山和雾。

## 7. 品质门槛（逐张自检）

1. 缩到 25% 仍能一眼认出：标题、主塔字、首领。
2. 没有矢量硬边的大色块，没有纯 `#000` 或纯 `#fff`。
3. 同屏彩色塔字不超过 3 种，朱砂面积不超过 8%。
4. 文字只有标题（壁纸为零）。
5. 放大到 100% 检查：没有锯齿、色带断层，纸纹不重复。
