# 融合塔设计方案

## 一、同类型融合

| 融合组合 | 结果 | 描述 |
|---------|------|------|
| 火+火 | 炎 | 强化火焰攻击，持续灼烧 | 
| 水+水 | 淼 | 强化水流攻击，持续减速 |
| 山+山 | 岳 | 强化山脉，高血量阻挡 |
| 木+木 | 林 | 强化木塔，持续中毒 |
| 金+金 | 鑫 | 强化金塔，穿透攻击 |
| 雷+雷 | 霆 | 强化连锁效果 |
| 冰+冰 | 凌 | 强化冻结效果 |
| 毒+毒 | 蛊 | 强化中毒效果 |
| 风+风 | 岚 | 强化击退效果 |
| 光+光 | 辉 | 强化穿透效果 |
| 暗+暗 | 冥 | 强化生命偷取 |
五行	单字	双叠字	三叠字
金	金	鍂 (两个金)	鑫 (三个金)
木	木	林 (两个木)	森 (三个木)
水	水	沝 (两个水)	淼 (三个水)
火	火	炎 (两个火)	焱 (三个火)
土	土	圭 (两个土)	垚 (三个土)
