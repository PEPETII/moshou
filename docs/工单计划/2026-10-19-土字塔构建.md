# 工单：构建「土」字炮塔（第二座新增字形塔）

- 日期：2026-10-19
- 类型：新塔 / 字形弹道玩法扩展
- 前置确认：与火、水同构（笔画写出「土」字做弹道）；先接入实际战斗可试玩，商店、图鉴文案深化与平衡调优后续再谈。

## 一、任务目标

1. 新增第三座字形塔「土」，具备与火、水一致的整套机制：三笔笔画、按笔顺写回、圆相蓄力、自动大招、打击反馈。
2. 让「土」真正进入实际战斗：塔防底栏可选、征服召唤池可召、图鉴可查（因图鉴由 `ACTIVE_TOWERS` 自动派生，必须同步给出文案与配色，否则会出现空白条目）。
3. 保持火、水行为零回归，`npm test` 全绿。

## 二、当前问题 / 背景

现有玩法只有火（追踪点 + 焚）与水（水箭 + 潮）。土在 `CONFIG.TOWERS` 里只有旧单字塔的遗留字段（aoe、aoeRange、unlockLevel），没有笔画数据、没有 `GlyphEarth` 实现，`GlyphTower.impl()` 也未登记，直接加进塔池会退化成「水」的招式并错色。

## 三、玩法设计（本次落地版）

- 字形：三笔，笔顺 横（上）→ 竖 → 横（下）。
- 普攻「落石」：上横化作石片直线飞出，命中首个敌人造成伤害、轻微击退，并在落点周围造成一次碎石溅射（对小范围其余敌人造成较低伤害）。
- 大招「陷」：三笔整体砸向射程内敌群最密处，落点造成一次震荡（伤害 + 定身 + 外推），随后地面留下一个「土」字陷坑，持续数秒：周期性碾压伤害并把范围内敌人按住（短定身），到时褪成墨痕。
- 定位：短射程、慢节奏、重控场，与火（持续灼烧）水（击退减速）区分。

## 五、实施步骤

1. 配置：`GLYPHS.earth` 三笔；`GLYPH_COLORS` 增土色三档；`GLYPH_MOVES_RAW.earth` + `PX_KEYS.earth`。
2. 实现 `GlyphEarth`：`update`（普攻）、`cast`（落点选敌群最密处）、`updateShot`（slab / quake / pit）、`drawShot`。
3. 调度：`GlyphTower.impl` 识别 earth；`GlyphTower.draw` 按类型取色与光晕。
4. 接入：`ACTIVE_TOWERS` 加 earth；`index.html` 挂脚本；图鉴文案与配色。
5. 测试：补齐土塔用例（笔画数量、普攻命中与溅射、蓄满自动大招、地面陷坑定时伤害与定身、绘制不抛错）。
6. 浏览器实测：塔防 1-1 放置土塔验证普攻/大招/塔卡；征服召唤池出现土塔。

## 六、风险与注意事项

- `GlyphTower.impl()` 是唯一分派点，漏改会让土塔静默使用水的招式（无报错、难发现），必须补断言。
- 土的定身复用 `Enemy.glyphStun`，与水的「潮」共用 `stun` 字段；同一敌人同时被两者命中取较大值，不会叠加，可接受。
- 陷坑是 `ground: true` 的地面弹道，绘制顺序在敌人之下；不能误用普通弹道通道，否则会盖住敌人。
- 新增数值全部按「原型像素 × GLYPH_SCALE」约定放到配置，禁止在 code 里写死像素。
- 本次不改动火、水的任何参数与分支。

## 七、验收标准

1. 塔防底栏出现「土」卡（造价与配置一致），放置后开始写「土」字，写满上横后能打出石片。
2. 蓄满后自动释放「陷」：落点范围内敌人掉血并被定身，地面出现「土」字陷坑，持续期间持续掉血，到时消失。
3. 征服模式召唤池包含土塔且可正常攻击。
4. 图鉴中土塔条目有笔画序号、两式文案与土色，不出现空白或火色。
5. `npm test` 全绿；`check:line-count` 通过（新增文件 < 600 行）。
