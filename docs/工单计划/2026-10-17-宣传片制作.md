# 宣传片制作

## 任务目标

在 `上架素材/宣传片/` 产出一支符合平台要求的游戏宣传片：

- .mp4，H.264，16:9，1920x1080（≥1280x720），30fps，横屏，时长 ≥15s（计划约 45s）。
- 带背景音乐（使用游戏自带的程序化合成音乐引擎录制，无人声）。
- 内容不得与此前的实机录屏高度雷同：本片不复用实机录屏流程，全部用水墨动画重新演绎。
- 画面文字只出现游戏标题「墨守成规」，不放字幕、宣传语、游戏图标。

## 当前问题 / 背景

- 已有素材：6 张截图、1 支 75.8s 实机录屏（拖拽布塔流程）、1 张 16:9 宣传图。缺宣传片。
- 游戏音频（`js/audio.js`、`js/audio-cues.js`、`js/audio-bgm.js`）是 Web Audio 实时合成，需要在浏览器里实时录制后转码。

## 涉及文件

- 新增 `scripts/promo-video/`：`stage.html`、`ink.js`（水墨绘制工具）、`storyboard.js`（分镜与战场模拟）、`render-frames.js`、`record-music.js`、`build-video.js`。
- 输出 `上架素材/宣传片/墨守成规-宣传片.mp4`。
- 新增 `docs/完成报告/2026-10-17-宣传片制作.md`。
- 不改动游戏源码。

## 实施步骤

1. 用 Canvas 2D 写确定性（按时间 t 渲染）的水墨动画：起笔泼墨 → 山水与路径成形 → 炮塔字落位 → 敌群来袭与弹道 → 「合字」融合特写 → 首领来袭与终局 → 标题定格。
2. Playwright 逐帧渲染 1920x1080 JPEG，保证帧间确定性。
3. 用游戏音频引擎在浏览器里按分镜时间表实时录制 BGM + 少量音效（落塔、合字、开波），转 AAC。
4. ffmpeg 合成 H.264 + AAC，响度归一，加渐入渐出。
5. 校验时长、编码、分辨率、音轨、响度，抽帧人工检查。

## 风险与注意事项

- BGM 为随机游走旋律，每次录制不同；录制后检查电平，必要时重录。
- 音画为分别生成再合成，同步点（落塔、合字）靠时间表对齐，精度约 ±0.1s。
- 外链字体依赖网络（Ma Shan Zheng），渲染前等待字体就绪。
- 不得出现游戏图标（不使用「守」字印章），不加字幕。

## 验收标准

- mp4 为 H.264 + AAC，16:9，1920x1080，≥15s，有音轨且非静音，体积远小于 5GB。
- 画面除标题外无其他文字；与实机录屏无雷同镜头。
