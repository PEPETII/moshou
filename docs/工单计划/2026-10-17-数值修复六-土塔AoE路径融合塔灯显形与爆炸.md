# 工单：数值修复六 —— A12 土塔 AoE 半径 / A13 路径融合塔攻击 / 灯显形 / 死亡爆炸对象

日期：2026-10-17　来源：审计报告 A5 末段、C2、修复四完成报告中的新发现 A12、A13（用户已授权按全部阶段连续修改）

## 任务目标
1. A12：`aoeAttack` 使用 `aoeRange`（土 2.2 格）作为半径，不再误用 `range`（3.2 格）；融合土系继承 `aoeRange`。
2. A13：带射程的路径融合塔（山清水秀、火山等）在 `onPath` 分支内也能按冷却攻击。
3. 灯(lantern)显形：`takeDamage` 判定改为 `invisible && !revealed`。
4. 敌人死亡爆炸（swiftGhost/bomber/doomsday）改为伤害有血量的炮塔（路径塔），不再误伤其他敌人。

## 当前问题/背景
- 土塔 AoE 半径 3.2 格（配置 2.2），融合土系只有基类默认 1.5。
- 融合路径塔在 `Tower.update` 的 onPath 分支直接 return，永不攻击。
- 灯只设置 `revealed`，`takeDamage` 只看 `invisible`，对永久隐身敌人无效。
- `triggerExplosion` 只遍历敌人，爆炸型敌人是在帮玩家清场。

按上述四条实现并写回归测试，重跑审计模拟记录基线变化。

## 风险与注意事项
- 土塔变弱（半径 3.2→2.2 格），属于回到配置意图。
- 爆炸型敌人对路径塔的伤害为新增压力，征服模式炮塔无血量故不受影响。
- 不改任何配置数值。

## 验收标准
- 土塔 AoE 半径等于 `aoeRange`；融合土系同样。
- 融合路径塔在射程内对敌人造成伤害。
- 灯范围内的永久隐身敌人可被伤害。
- 敌人死亡爆炸只伤害有血量的炮塔，不再伤害敌人。
