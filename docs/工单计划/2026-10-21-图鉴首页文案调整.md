# 图鉴首页文案调整（鬼 → 敌，删除三行副标题）

日期：2026-10-21
状态：已完成

## 任务目标

1. 图鉴首页「妖异录」入口卡的大字图标由「鬼」改为「敌」。
2. 删除三张入口卡的副标题文案：`字形如何写成弹道`、`来犯者的血量与脚程`、`两字相邻，合成新字`。

## 当前问题 / 背景

图鉴首页（`#encyclopedia-container`）三张入口卡目前是「大字 + 分区名 + 副标题 + 已录条数」四层信息。副标题属于解释性文字，在小横屏上占比不小、信息价值低；「鬼」作为妖异录的图标字，与项目内统一使用的「来犯之敌」表述不一致。

## 涉及文件

| 文件 | 改动 |
| --- | --- |
| `js/bootstrap/page-markup.js` | 妖异录卡 glyph 由「鬼」改「敌」；删除三个 `codex-entry__desc` span |
| `css/ink-ui/codex.css` | 删除 `.codex-entry__desc` 规则（样式已无对应元素） |

## 实施步骤

1. 改 glyph 文本。
2. 删除三行副标题 DOM。
3. 清理 CSS 中 `codex-entry__desc` 规则。
4. 校验没有脚本依赖该 class；卡片本身 `justify-content: center`，删行后自动垂直居中。

## 风险与注意事项

- 仅改图鉴首页入口卡。**妖异录内的敌人条目名（含名为「鬼」的敌人）与战斗内敌人称谓不改**，刷怪、数值、图鉴数据完全不动。
- `已录 12 字 / 3 种 / 3 字` 计数逻辑在 `js/ui/encyclopedia.js`，不触碰。
- 删掉副标题后卡片只剩三层信息，需确认卡片没有出现内容偏上、留白失衡。

## 验收标准

- 图鉴首页第二张卡大字显示「敌」，三张卡均无副标题行。
- 三卡等宽、内容垂直居中，计数标签仍在卡片底部区域可见。
- 640×360 与 844×390 横屏下三卡完整可见，点击仍进入对应分区。
