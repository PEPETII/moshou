# 工单：修复手机端自定义子界面返回按钮不可见

## 任务目标
修复在手机（横屏矮视口）上进入「自定义」的三个子界面（自定义炮塔 / 自定义关卡 / 导出/导入）后，返回按钮不存在/不可见的问题。

## 当前问题/背景
- 返回按钮 `#back-to-custom-from-towers` / `#back-to-custom-from-levels` / `#back-to-custom-from-export` 在 DOM 中存在（js/bootstrap/page-markup.js:223/236/249）。
- `#main-menu` 为 `position:fixed; height:100%` 的 flex 居中容器且不可滚动（css/inline/part-01.css）。
- 手机横屏（视口高度 ≤400px）时，子界面内容总高（大标题 + 占位卡片大内边距 + 按钮外边距）超出视口，`justify-content:center` 导致上下两端同时被裁切，返回按钮落到可视区之外，且无法滚动，用户被卡死在该界面。
- 桌面端视口较高，故未暴露。

## 涉及文件
- css/style/part-04.css（新增移动端媒体查询）

## 实施步骤
1. 在 css/style/part-04.css 追加 `@media (max-height: 500px) and (orientation: landscape)` 查询：
   - 压缩 `.custom-sub-title`、`.custom-sub-header`、`.custom-placeholder` 及其子元素、三个返回按钮的尺寸与间距；
   - 占位卡片 `min-width` 改为响应式（`min(90vw, 480px)`）；
   - 给 `#main-menu` 加 `overflow-y: auto` 兜底，防止其他内容溢出时无法滚动。

## 风险与注意事项
- 仅在矮横屏视口生效，不影响桌面端现有布局。
- 纯 CSS 改动，无逻辑风险。

## 验收标准
- 手机横屏下进入三个自定义子界面，返回按钮完整可见且可点击。
- 桌面端自定义界面外观不变。
