## 1. 任务目标

### A. HUD 修正
1. **地图零遮挡**：把「墨 / 守时 / 尸」和核心「守 x/y」从画布上方移进右侧卡槽，竖排放在塔卡下方，与征服的左侧竖条同构；画布上方不再有任何叠放。缩放率和镜头余量不变（卡槽宽度不变）。
2. **关卡名**移到暂停面板，作为标题下方的副标题。
3. **数字字体**：数值改用伤害数字的字体（`CONFIG.FONTS.BRUSH`，即 `var(--font-brush)`，Ma Shan Zheng）；数值留固定宽度，避免跳字。征服竖条的数值同步改用这一字体，保持两种模式一致。

### B. 收尾清理
1. 删除下架玩法的遗留：`showEventNotification`、`showMerchantEvent`（全仓没有任何调用）以及 `.event-notification`、`.merchant-inscription`、`#event-container` 的样式和结构。
2. 删除孤立的 `#sound-toggle`、`#bgm-toggle` 规则（对应元素已在 P4 移除）。
3. 用脚本找出旧样式中「选择器里的所有 ID 和类在 HTML / JS 中都已不存在」的规则，予以删除。
4. `toast.js` 的内联色值改用令牌。
5. **检查接入 `npm test`**：
   - `check:syntax`：对 `js/`、`scripts/`、`tests/` 下所有 JS 执行 `node --check`（P5 中出现过测试发现不了的语法错误）；
   - `check:tokens --strict` 改为「只升不降」的棘轮：以当前各文件的违规数为基线（`scripts/tokens-baseline.json`），任何文件超过基线、或新文件出现违规时失败。旧样式中的存量逐步消化，不要求一次清零。

## 4. 风险与注意事项

- 卡槽高 432 个逻辑 px：暂停按钮（约 59）、两张塔卡（2×70）、间距，再加四个数值（每个约 40），合计约 380，放得下；矮屏缩放时数值字号用 `--bfs-*`。
- 「尸」计数在卡槽中可能出现三位数，数值区宽度按「三位数 + 斜杠」留够。
