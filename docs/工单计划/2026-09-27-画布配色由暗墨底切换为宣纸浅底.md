# 工单：画布配色由「暗墨底飞白」切换为「宣纸浅底落墨」

- 日期：2026-09-27
- 类型：视觉 / 主题配色
- 影响面：Canvas 渲染层 + 颜色配置常量

## 1. 任务目标

将游戏画布的明暗极性反转，由「黑底飞白」改为「浅纸落墨」，使画面呈现宣纸质感。

指定的五处颜色变更：

| 语义 | 原值 | 新值 |
|---|---|---|
| 画布纸底 | `#0c0c0c` | `#f4efe4` |
| 文字 | `#e8e8e8` | `#1c1a17` |
| 网格线 | `#1f1f1f` | `#ded5c0` |
| 敌人颜色 | `#cccccc` | `#1c1a17` |
| 辅助文本 | `#8a8a8a` | `#6a6459` |

## 2. 约束条件（硬约束）

**「文字炮塔放置后的字体颜色不修改」。**

即：塔格中渲染的汉字本身保持原有色值，本工单不得改动：

- `CONFIG.COLORS.tower`（`#e8e8e8`，飞白）
- 各元素塔字色：`#ff6600` / `#00aaff` / `#90b090` / `#ffd700` / `#8b7355` / `#64b4dc`
- `CONFIG.COLORS.thunder` / `ice` / `poison` / `wind` / `light` / `dark` / `star` / `frost` 等元素色
- `CONFIG.COLORS.highlight`（`#d4d4d4`）—— 该值是「塔被选中时」的字体色，属炮塔字体范畴

因此本次「文字」的语义判定为：**画布通用文字与墨色**（`CONFIG.COLORS.text`、`InkRenderer.drawInkText` 默认色、HUD 文本），不含炮塔字形。

## 3. 当前问题 / 背景

- 原型 `prototypes/04-墨为血.html` 使用 `PAPER #f4efe4` / `INK #1c1a17` / `CINNABAR #b03a2e` 的浅纸体系；
  当前主线走的是 `bg #0c0c0c` 暗场体系，两者明暗极性相反。
- 切换为浅底后，所有原为「浅色 = 可见」的深色系元素会自动变为可见，
  但所有原本依赖「在黑底上发亮」的浅色元素会失去对比度。

## 4. 涉及文件

| 文件 | 改动内容 |
|---|---|
| `js/config/domain-03.js` | `COLORS.bg` / `grid` / `enemy` / `text` / `textDim` |
| `js/inkRenderer.js` | `drawInkText` 默认色 `#e8e8e8` → `#1c1a17`；文字投影改为浅底可用的墨晕 |
| `js/core/rendering.js` | 硬编码辅助文本色 `#888`（关卡名）、`#666`（入口） |
| `js/entities/enemy/rendering.js` | 敌人状态变体色（蒸发 / 灼烧 / 减速 / 阻挡）随主色深色化 |
| `js/modes/conquest/rendering.js` | 征服模式清屏色（复用 `COLORS.bg`，需确认无独立硬编码） |

**明确不改动**：`js/entities/towers/rendering-basic.js`、`rendering-advanced.js`、`misc.js`、`fusion.js` 中的任何字形颜色。

## 5. 实施步骤

1. 修改 `js/config/domain-03.js` 的 `COLORS` 五项主色。
2. 修改 `js/inkRenderer.js` 的 `drawInkText` 默认文字色与飞白高光逻辑。
3. 清理 `js/core/rendering.js` 中画布内硬编码的辅助文本色。
4. 同步敌人状态色，避免状态反馈在浅底上消失。
5. 用无浏览器 Canvas 夹具渲染实际帧 PNG，肉眼复核可读性。
6. 输出完成报告，列出浅底后仍存在对比度风险的元素清单。

## 6. 风险与注意事项

- **炮塔字形对比度风险（已知且本次不修）**：深底专用的浅色塔字（`#e8e8e8` 飞白、`#d4d4d4` 选中态）在 `#f4efe4` 浅底上对比度极低，可能接近不可见。受硬约束限制本次不改，验证后向用户反馈。
- **UI 外壳未同步**：`css/*.css` 的页面背景仍为 `#0c0c0c`，画布变浅后与外壳存在明暗割裂。本次范围仅画布，外壳作为后续项。
- **墨晕/投影方向**：`drawInkText` 的阴影原为 `rgba(0,0,0,0.3)` 偏移 +2px，浅底上仍可充当墨晕，保留但需确认不过度糊化。
- **路径与远山**：`COLORS.path #2d2d2d`、`drawDistantMountains` 为深色，在浅底上自然可见，本次不动。
- 不得为规避行数限制压缩代码；本工单仅改颜色常量，不涉及结构拆分。

## 7. 验收标准

- 画布底色为 `#f4efe4`，网格线为 `#ded5c0`。
- 敌人为深墨 `#1c1a17`，辅助文本为 `#6a6459`。
- 通用文字（含 `drawInkText` 默认）为 `#1c1a17`。
- 炮塔字形颜色与改动前逐字节一致（硬约束）。
- 渲染出的帧中，底色、网格、敌人、辅助文本四项肉眼可辨。
- `node` 侧无语法错误，页面可正常加载。
