## 五、风险与注意事项

- 公开仓库推送不可回退敏感信息：扫描无命中方可推送；本次改动的截图与文档需确认不含私密内容。
- 21 MB PNG 一次性入库会永久占用仓库体积，但 4 份完成报告均以相对路径引用这些截图，保留可使 GitHub 端文档自洽。
- Git 对 LF 文件提示 `LF will be replaced by CRLF`，属 `core.autocrlf` 的既有行为，不影响内容。
- 若代码提交遗漏 `earth.js` / `wood.js`，远程会立即白屏或报错，需在推送后核对入口引用与文件清单一致。
