# 2026-10-21 上架素材更新与 H5 打包

## 任务目标

按新加坡发行平台的上架规格，重新产出全套上架素材，并打出 H5 zip 包：

| 素材 | 规格 |
|---|---|
| 宣传图 | 16:9，1920×1080 起，仅含游戏标题，无图标，JPG/PNG ≤4MB |
| 游戏截图 | 3–10 张实机截图，横图 8:3~8:5，≥1280×720，比例统一，≤4MB/张 |
| 宣传片 | 横屏 16:9，≥1280×720，≥15s，H.264，内容与实机录屏不雷同 |
| 实机录屏 | 约 30s，前 5s 内出核心玩法并持续 ≥10s，无配音字幕/画中画，H.264 |
| 游戏 Logo | 透明 PNG，宽 ≥1280 或高 ≥720，内容贴边不留白，高明度高识别 |
| 游戏库壁纸 | 3840×1240 起，禁任何文字，主体避开左侧 UI 区，≤10MB |
| 封面图 | 横版 ≥460×215、竖版 ≥600×900，必须带 LOGO 与标题，无其他宣传文字 |
| H5 包 | zip，解压为单一目录、内含入口 index.html，仅运行必需文件 |

## 当前问题/背景

`上架素材/` 下的旧素材（宣传图、截图、宣传片、录屏）产自 2026-10-19 字形弹道重构之前：截图里有已删除的旧塔（光、暗、风雷合字等）、48px 网格与手动开波次。`scripts/store-assets/` 的截图与录屏脚本已标注过时。Logo、壁纸、封面图此前没有产出。

## 涉及文件

- `scripts/store-assets/`：重写截图、录屏脚本，新增 Logo / 壁纸 / 封面 / 宣传图合成页与渲染脚本、校验脚本
- `scripts/promo-video/`：宣传片分镜按现行塔与敌人更新（或改为实机多关卡剪辑）
- `scripts/build-h5-zip.py`：H5 打包（核对白名单是否仍覆盖全部运行资源）
- `上架素材/`：全部产物
- 不修改游戏运行代码（js/、css/、index.html）

## 实施步骤

1. 核对现行游戏 API（开局、放塔、刷怪、镜头）与旧脚本差异。
2. 重写实机截图脚本：多主题关卡、十二座单字塔 + 合字塔、多字精英与首领，1920×1080 PNG。
3. 用游戏自身的水墨笔触与字形素材合成宣传图、Logo、壁纸、横竖封面（程序化渲染，不拼贴截图）。
4. 录制约 30s 实机录屏（开场即布塔交战），ffmpeg 转 H.264。
5. 制作宣传片：多关卡、首领、融合等高光片段剪辑 + 标题收尾，配游戏音乐，与录屏内容区分。
6. 校验脚本逐项核对尺寸、比例、大小、编码、时长。
7. 打 H5 zip，解压后本地静态服务冒烟运行。

## 风险与注意事项

- 字体来自 Google Fonts，渲染素材前须确认已加载，否则标题会落到系统字体。
- 实机截图必须是真实对局画面，可用调试接口布塔、补墨，但不得改动渲染结果。
- 宣传图须"贴近真实美术"，避免过度美化；Logo 需在深浅背景上都可辨识。
- 旧素材将被覆盖，旧文件已在 git 历史中保留。

## 验收标准

- 校验脚本全部通过。
- 截图只出现现行塔与敌人，比例一致，实机画面占满。
- 宣传图、壁纸、封面图、Logo 不含标题以外的文字；壁纸无任何文字。
- H5 zip 解压后通过静态服务能进入主菜单并开局。
