# 横屏手机端适配检查与 H5 打包

## 任务目标

1. 全方位检查游戏在横屏手机上游玩时已存在或可能存在的问题（布局缩放、安全区、触控交互、弹窗、字体离线、性能、音频解锁、横竖屏切换、控制台报错与资源 404），并修复。
2. 把可直接部署的 H5 游戏包体打成 zip，不包含 `.git`、`docs`、`上架素材`、`.gitignore`、`AGENTS.md`、`README.md`，以及开发用文件（`node_modules`、`tests`、`scripts`、`package*.json`、`midscene_run`、IDE/工具隐藏目录）。

## 当前问题 / 背景

- 项目已有设备探测（`js/bootstrap/device-profile.js`）、视口缩放（`js/bootstrap/viewport.js`）、触控拖拽（`js/ui/input-touch.js`）等适配，但没有系统性的手机横屏回归验证。
- 之前运行时观察到一条 404 资源请求，来源未确认。
- 字体来自 Google Fonts 外链，国内网络或离线时可能失败，需确认回退表现。
- 现有音效为 Web Audio，需确认移动端首次手势解锁。

## 涉及文件

- 检查范围：`index.html`、`js/bootstrap/*`、`css/**`、`js/ui/*`、`js/modes/conquest/touch.js`、`js/audio*.js`。
- 新增（仅检查工具）：`scripts/mobile-check/`。
- 修复将落在上述文件中；具体改动在完成报告中逐项列出。
- 输出：`E:\news-game\moshou-h5.zip`（放在项目目录外层，避免被打入包内）。
- 新增 `docs/完成报告/2026-10-17-横屏手机端适配检查与H5打包.md`。

## 实施步骤

1. 用 Playwright 模拟多种手机横屏视口（含刘海屏安全区、DPR 3、触摸），自动走完菜单、选关、塔防、征服、图鉴、融合弹窗流程，截图并收集控制台错误和失败请求。
2. 逐项审查：缩放与裁切、可点区域尺寸（≥44px）、触控拖拽放置与融合、弹窗溢出、文字最小字号、滚动与回弹、横竖屏切换、后台暂停、字体离线回退、性能。
3. 修复发现的问题，保持单文件不超过 600 行；涉及数值才跑平衡测试。
4. 运行 `npm test`。
5. 打包 zip，校验包内文件清单、解压后可运行。
6. 写完成报告。

## 风险与注意事项

- 无真机，仅浏览器移动模拟，不能覆盖厂商浏览器的个别差异。
- 不引入构建工具或 TypeScript；游戏数值不改。
- 修复不得破坏桌面端行为。

## 验收标准

- 模拟的手机横屏视口下，整套流程无控制台报错、无资源 404，布局不被裁切，触控可完成布塔、融合、开波次、图鉴浏览。
- `npm test` 通过。
- zip 内不含被排除的文件，解压后用静态服务可正常进入游戏。
