# 敌潮面板文案调整（择潮 → 敌潮，删除出怪数值行）

日期：2026-10-21
状态：已完成

## 任务目标

1. 敌潮选择弹窗标题由「择潮」改为「敌潮」。
2. 删除三档选项中的出怪数值文案：`每秒 X 只`（`density-rate`）与 `巨 每 Y 秒`（`density-giant`）。

## 当前问题 / 背景

开局前弹窗 `#density-picker` 标题为「择潮」，与项目内其他位置统一的「敌潮」表述不一致；同时每个选项把 `CONFIG.DENSITY` 的 `rate`、`giantEvery` 直接展示给玩家（每秒 1.6/3.4/6.5 只、巨每 14/9/5 秒），属于运行细节，不需要暴露在选档界面。

## 涉及文件

| 文件 | 改动 |
| --- | --- |
| `js/ui/density-picker.js` | 标题改「敌潮」；移除 rate、giant 两个 span |
| `css/ink-ui/battle.css` | 删除 `.density-rate` / `.density-giant` 样式；调整选项内部纵向留白 |

## 实施步骤

1. `_build()` 中标题文案改为「敌潮」。
2. 选项模板只保留 `density-label` 与 `density-desc`。
3. 清理 `battle.css` 中已无对应元素的样式规则，并给描述行补一点上间距，避免字与描述贴死。
4. 确认无测试/脚本依赖被删元素。

## 风险与注意事项

- 只改文案与结构，不触碰 `CONFIG.DENSITY` 的 `rate`、`giantEvery`，刷怪节奏不变。
- 选项内行数由 4 行降到 2 行，面板整体变矮；需保证矮横屏（`max-height: 500px`）下按钮区仍完整可见。
- 键盘快捷键 1/2/3 与默认选中「潮」的逻辑不受影响。

## 验收标准

- 标题显示「敌潮」，全弹窗无「每秒 / 巨 每」字样。
- 三个选项均只剩大字号名称与一句风格描述，卡片等宽、内容垂直居中。
- 960×432 与矮横屏 640×360 下弹窗完整可见，「返回 / 开战」可点击。
