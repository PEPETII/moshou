# 工单：P6 地图融合（纸纹共享 · 征服棋盘 · 卷底山水 · HUD 遮挡）

- 日期：2026-10-19
- 上级方案：[全界面横屏适配与水墨视觉统一](2026-10-19-横屏适配与水墨视觉统一.md) 第 3.3 节 ③；问题编号 C3；P4 遗留的「HUD 遮挡第 0 行」
- 依赖：P1–P5

## 1. 任务目标

1. **纸纹共享**：DOM 页面和画布地图使用**同一张宣纸**。由 `MapBackground` 的纸纹算法生成一张可平铺的纤维纹理（只生成一次），写入 CSS 变量 `--tex-paper-fiber`，供 `.ink-page`、卷轴弹层、面板、卡槽使用。这样从主菜单（画布纸）进入任何页面，纸张质感都一致。
2. **卷底山水**：用地图远山的同一套算法，生成一条透明底的远山带 `--tex-scroll-foot`，铺在所有 `.ink-page` 底部，与主菜单底图、战斗地图底边的远山同源，形成连续的「长卷」意象。
3. **征服棋盘去「方格纸」感**（C3）：
   - 保留「格位分区」：这是现有的设计决定（`conquest/rendering.js` 中的注释说明，空场时网格是唯一的分格依据，测试也约束了网格常驻）。
   - 把通长实线改为**只在格位交点出现的十字墨点**；把 80 块逐格纸色填充改为**一整块淡纸面**，标出可放置区域。
   - 每帧绘制量也随之下降：`fillRect` 从 80 次降到 1 次，网格笔数保持 30。
4. **HUD 减轻**：塔防 HUD 底纹更矮、更透明，减少对第 0 行敌人的遮挡。

## 2. 当前问题 / 背景（已核对代码）

- DOM 页面的纸纹是 SVG 噪点（`ink-texture.css` 的 `--tex-paper`），画布地图的纸纹是 `mapBackground.js` 的 `paintPaper`（纤维加茶渍）。两者颗粒不同，进出页面时纸张会「换一张」。
- 主菜单和战斗地图的底边有远山（`paintMountains`，透明度 0.03–0.05），图鉴、选关、设置页没有。
- 征服地图：`drawGrid` 每帧画 30 条 1px 通长实线（`#ded5c0`），`drawPlacementArea` 每帧对 20×4 内格逐个填半透明纸色，两者叠加形成明显的方格纸。`tests/test-grid-visibility.js` 断言征服 `drawGrid` 在空闲和拖拽时都画 23+7 笔。
- 塔防 HUD（P4）：底纹高约 36 个逻辑 px，透明度 0.92。

## 4. 实施步骤

1. 在 `mapBackground.js` 中实现两个导出（复用 `paintPaper` 的纤维算法和 `paintRange`）。平铺纹理在四边做环绕绘制，保证无缝。
2. 编写 `paper-texture.js`：调用导出函数，转为 `toDataURL` 后写入根元素的变量；失败时静默跳过。
3. 各纸面背景改为 `var(--tex-paper-fiber), var(--tex-paper)` 叠加。
4. 改造征服的网格和放置区；跑 `test-grid-visibility`。
5. 减轻 HUD；巡检并截图对比；运行 `npm test`。

## 5. 风险与注意事项

- **性能**：纹理只在启动时生成一次（512×512 纤维、960×120 远山），之后由浏览器作为背景图缓存；不改变战斗中每帧的绘制（征服反而少了 79 次 `fillRect`）。生成耗时要实测记录。
- **数据 URI 体积**：PNG 体积要控制在约 300KB 以内；如果过大，可以降低纤维密度或改用 WebP。
- **测试约束**：征服网格仍画 30 笔，空闲和拖拽时都常驻；`setLineDash` 在测试的模拟对象中不存在，调用前要判断。
- **纸色**：`paintPaper` 的底色常量 `PAPER #f4efe4` 与 `--paper-0` 相同，可以直接平铺在 `--paper-0` 上。面板（`--paper-1`）上的纹理要用透明底版本，否则会把面板颜色盖掉。所以平铺纹理只画纤维、不画底色。

## 6. 验收标准

1. 进入图鉴、设置、选关页时，纸张纹理与主菜单画布同源（截图对比），底部有淡淡的远山。
2. 征服地图不再呈现方格纸：只有交点十字和整块淡纸面；可放置区与环形路径仍然分明。
3. `test-grid-visibility` 原有断言不改，仍然通过。
4. 纹理生成耗时和数据 URI 体积有实测数据，并在可接受范围内（例如生成 < 50ms，体积 < 300KB）。
5. 在横屏矩阵中重跑 P2–P5 的巡检，全部通过；`npm test` 通过。
