# 区域1标题仅首页显示

## 任务目标

仅在主菜单首页显示区域1标题 `<h1 aria-label="墨守成规">`；打开塔防主题/关卡、征服、图鉴、自定义等子页面时隐藏，返回首页时恢复。

## 当前问题/背景

标题位于 `#main-menu` 内，而该容器也承载多个菜单子页面。切换子页面时通常只隐藏 `.menu-buttons`，所以标题仍然留在子页面上。

## 涉及文件

- `js/bootstrap/page-markup.js`
- `js/ui/menu.js`
- `js/ui/conquest.js`
- `js/ui/encyclopedia.js`
- `docs/工单计划/2026-09-28-区域1标题仅首页显示.md`
- `docs/完成报告/2026-09-28-区域1标题仅首页显示.md`

## 实施步骤

1. 检查首页按钮、普通模式、征服、图鉴和自定义页面的显隐调用链。
2. 添加可访问的标题容器标识，并在菜单主按钮隐藏/恢复时同步标题显示状态。
3. 为普通关卡列表、征服、图鉴等自行控制主按钮显隐的入口接入相同状态同步。
4. 根据关卡选择页截图补齐具体关卡列表入口，并执行针对性静态/行为验证。

## 风险与注意事项

- 首页入口可能通过多个模块切换，需避免标题状态与主按钮状态分离。
- 不覆盖工作区已有的 `js/bootstrap/page-markup.js`、`js/ui/conquest.js`、`js/ui/menu.js` 用户改动。
- 不修改主菜单以外的游戏标题、加载文字或游戏流程。

## 验收标准

- 初始主菜单首页标题可见。
- 普通塔防主题/关卡、征服主题/关卡、图鉴主界面/子页、自定义主界面/子页中标题隐藏。
- 返回主菜单首页后标题恢复显示。
- 区域1文案和现有页面布局行为不变；验证范围及结果可检查。
