# 工单：货币系统「金币 → 墨水」统一替换

## 任务目标
将游戏货币从「金币」全面更名为「墨水」，覆盖变量名、配置、UI 文案、DOM id 与注释，数值逻辑不变。

## 当前问题/背景
货币在代码中命名为 `gold`（`game.gold`、`startGold`、`goldPerWave` 等），UI 文案为「金币」「X金」。
注意：**金行塔（元素 `type: 'gold'`）与货币无关，不得改动**，包括：
- `config/fusion.js` 融合配方（gold+gold 等）、`config/domain-02.js` 的 `gold:` 元素键
- `rendering-basic.js` 的 `drawGoldTower`、`entities/towers/combat.js` 的类型判断
- `data/levels/*.js` 的 `unlocks: ["gold"]`、`conquest/waves.js` 的 towerTypes 中的 "gold"
- `inkTrailAnimation.js` 的 `gold` 颜色、图鉴类型检查

## 涉及文件
- 逻辑：js/game.js、js/tower.js、js/core/{towers,flow,misc,waves,rendering}.js、js/fusionSystem.js、js/entities/towers/misc.js、js/entities/enemy/lifecycle.js
- 征服模式：js/conquestGame.js、js/conquestLevelsData.js、js/modes/conquest/{fusion,misc,flow,waves}.js
- 关卡数据：js/data/levels/part-01.js、part-02.js、js/levelManager.js（仅 `startGold`→`startInk`）
- 配置：js/config/domain-02.js（仅 goldPerWave 系 + 文案）
- UI：js/ui/{menu,panels,input,input-touch,toast,encyclopedia,fusion}.js、js/bootstrap/page-markup.js
- 样式：css/style/part-01.css、part-03.css、part-05.css（id 与注释）
- 测试：tests/test-balance.js（内联配置的 goldPerWave 同步改名）

## 实施步骤
1. 脚本化替换（带白名单与引号保护）：
   - `goldPerWaveInc→inkPerWaveInc`、`goldPerWave→inkPerWave`、`startGold→startInk`
   - `insufficient_gold→insufficient_ink`
   - `getElementById("gold")→("ink")`、`getElementById("conquest-gold")→("conquest-ink")`
   - 属性/标识符 `.gold`、裸 `gold` → `ink`（先保护引号内的元素 "gold" 字符串）
   - 文案：`金币→墨水`、`金/波→墨/波`、`产金→产墨`、` 金）→ 墨）`、`"金"→"墨"`（限图鉴/融合 UI）、`}金→}墨`（限 flow.js）
   - DOM id：`id="gold"→id="ink"`、`id="conquest-gold"→id="conquest-ink"`；CSS 选择器同步
2. grep 复核：确认无遗漏的货币 gold/金币，且元素 "gold" 未被误改。
3. node --check 语法校验全部改动 js 文件。

## 风险与注意事项
- 存档/状态对象键 `gold:` 改为 `ink:`，读写两侧均在改动白名单内，同步改名；若存在旧存档持久化则不兼容（当前为内存态，无此问题）。
- 引号内元素字符串 "gold" 必须保留；`startGoldRanges`、`goldRange` 等含 gold 的复合标识符不受 `\bgold\b` 影响。
- `tests/test-balance.js` 自带内联 CONFIG、不加载源码，其 3 项长期不达标为既有数值问题，与本次无关。

## 验收标准
- 全项目无货币含义的「金币/gold」残留（元素金塔除外）。
- 货币数值计算、增减、显示逻辑行为不变；`node --check` 全部通过。
