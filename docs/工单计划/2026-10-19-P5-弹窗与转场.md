## 1. 任务目标

1. **统一「卷轴弹层」**：胜负弹窗、择潮、暂停、战斗设置共用一种面板：一层纸面、上下两根卷轴墨杆、四角飞白；去掉现在的「多层错位纸张」（`box-shadow: 8px 8px 0`）和上下粗细不一的实线（C4）。遮罩也统一为同一种淡墨。
2. **胜负弹窗重做**（B6）：
   - 大字「胜 / 破」加盖印动画；塔防胜利时，星级显示为**三枚朱印**（亮或暗），不再用「★★☆」纯文本；赏墨单独一行。
   - 按钮组：

     | 情形 | 按钮（最右为朱红主按钮） |
     |---|---|
     | 胜利，有下一关 | 重来 / 选关 / **下一关** |
     | 胜利，没有下一关 | 重来 / 主菜单 / **选关** |
     | 失败 | 主菜单 / 选关 / **重来** |

     征服也一样，只是没有「主菜单」：胜利为 重来 / 选关 / **下一关**；失败为 选关 / **重来**。
   - 塔防和征服共用一个渲染函数，不再各写一套（征服目前有 `showModal` 和 `showVictoryModalWithNextLevel` 两套逻辑）。
3. **墨晕转场**（C5）：所有 `.ink-page` 页面、主菜单首页出现时，从最近一次点击的位置以墨晕形式展开（`clip-path` 圆形展开加淡入，约 280ms）；开启减少动效时直接切换。

## 5. 风险与注意事项

- 胜负音效由 `InkUI.setModalScene` 触发，新实现必须继续调用它。
- 胜利时 `markLevelCompleted` 和赏墨计算的顺序不变，只改展示。
- 「重来」走现有的 `restartLevel` / `startLevel`，不新增流程。
- 转场只用 `clip-path`、`opacity`，不使用 `filter`；`display:none → 显示` 时动画自动重播，不需要额外的 JS 状态。
- 巡检会触发胜负并写入本地进度（`localStorage`），只在 Playwright 的临时环境中进行，不影响用户的浏览器。
