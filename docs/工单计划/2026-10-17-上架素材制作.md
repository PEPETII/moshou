# 上架素材制作（截图 / 录屏 / 宣传图）

## 任务目标

在项目根目录新建 `上架素材/`，生成符合平台规范、可直接上传的三类素材：

1. 游戏截图（≥3 张，PNG/JPG，≤4MB，横图 8:3~8:5，≥1280x720，比例一致，实机占比 >50%）。
2. 实机录屏（MP4 / H.264，≥15s，前 5s 展示核心玩法且持续 ≥10s，无人声、字幕、设备边框，短边 ≥540px）。
3. 16:9 宣传图（仅含游戏标题文字，无图标，非截图/拼贴，贴近真实美术）。

## 当前问题 / 背景

- 暂无任何上架素材。游戏画布固定 960x432（20:9），需等比放大到不低于 1280x720 的尺寸。
- 环境：Playwright 1.59.1 已装，但本机只有 chromium-1187，需指定 executablePath；ffmpeg 使用 Python imageio-ffmpeg 自带二进制。

## 涉及文件

- 新增 `上架素材/`（截图、录屏、宣传图三个子目录）。
- 新增 `scripts/store-assets/`：截图、录屏、宣传图的生成脚本（不改动游戏代码）。
- 新增 `docs/完成报告/2026-10-17-上架素材制作.md`。

## 实施步骤

1. 起本地静态服务，用 Playwright 驱动真实游戏进入关卡、放置/融合炮塔，截取战斗画面。
2. 用 Playwright 录制战斗过程，ffmpeg 转码为 H.264 MP4。
3. 以游戏水墨美术元素渲染 16:9 宣传图，仅放标题。
4. 脚本校验尺寸、比例、体积、编码并写完成报告。

## 风险与注意事项

- 外链字体（Google Fonts）离线时会回退，需确认画面字体正常。
- 录屏前 5s 内必须已进入战斗；不得露出菜单以外的商业内容。
- 不修改游戏源码；脚本放 `scripts/store-assets/`，符合 600 行限制。

## 验收标准

- 截图 ≥3 张、尺寸/比例/体积达标且比例一致。
- 视频 ≥15s、H.264、短边 ≥540px，前 5s 即为核心玩法。
- 宣传图 16:9，只有标题文字，无图标。
