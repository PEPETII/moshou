# 02 山字塔改为非路径塔

- **所属模块**：炮塔配置（`js/config/domain-02.js`、`js/config/glyphs-ext.js`）、山塔招式（`js/glyph/mountain.js`）、图鉴文案（`js/config/codex.js`）、测试
- **依赖**：无。「镇」光环要等 07 的能力框架完成后才有作用对象，但可以先实现接口。

## 1. 目标

山不再挡路，也没有生命值，和其它塔一样放在路边的可建造格上。挡路这个定位去掉以后，给山一个**新定位：「镇」——压制敌人的特殊能力**，正好克制本次新增的大量带能力敌人。

## 2. 当前问题和背景

- `CONFIG.TOWERS.mountain` 的配置是 `onPath: true, hp: 260`，只能放在路径格上，敌人走到它前面会停下来攻击它（`Enemy.checkBlocking` → `RuntimeIndexes.blockingTowerByCell`）。
- 大招「崩」会回满生命，这个效果是给路径塔准备的。
- 测试 `test-glyph-towers.js` 第 33、45、196～205 行、`test-fusion.js` 第 55 行都按「山是路径塔」写的断言。

## 3. 具体规格

### 3.1 配置

```js
mountain: {
  char: "山", cost: 145, size: 68,
  // 删除 onPath、hp
  desc: "普攻「峰刺」：三笔化作石刺，从最前三名敌人脚下拱出。被动「镇」：射程内敌人的特殊能力冷却变慢。大招「崩」：沿最近的路段双向震荡，击退并眩晕（蓄满自动释放）。",
}
```

`GLYPH_MOVES_EXT.mountain`：

| 字段 | 旧值 | 新值 | 说明 |
|---|---|---|---|
| `range` | 170 | 185 | 不在路上了，射程略放大，弥补站位变远 |
| `spikeDamage` | [14, 18] | [16, 21] | 失去挡路价值，补一点输出 |
| `quakeHeal` | 1 | **删除** | 不再有生命值 |
| `quakeDamage` | 30 | 38 | |
| 新增 `suppressRadius` | — | 同 `range` | 「镇」光环半径（[px]，要加进 `pxKeys`） |
| 新增 `suppressRate` | — | 0.6 | 光环内敌人能力冷却的流逝速度倍率（数值越小冷却越慢） |
| 新增 `suppressBossRate` | — | 0.8 | 对四字首领只打八折 |

### 3.2 被动「镇」

- 每帧在山的射程内找敌人，把 `enemy.abilityTimeScale` 设为 `suppressRate`。多座山**不叠加**，取最小值，并且不低于 `CONFIG.CONTROL.suppressFloor`（初值 0.6，见 12）。
- 能力框架（07）的冷却计时统一按 `dt × abilityTimeScale` 递减；每帧开始时把 `abilityTimeScale` 重置为 1。
- 表现：射程圈以内用淡墨画出山形底纹（透明度 0.08），被镇住的敌人头顶显示一个小「镇」字（字号 10，透明度 0.6）。

### 3.3 大招「崩」

- 删除回血和回血飘字（`GlyphFX.number(t, t.maxHp * …)`）。
- 击退、眩晕改为走 12 的统一接口：`ControlRules.knock(e, dist, 'mountain')`、`ControlRules.stun(e, dur, 'mountain')`。首领、三字敌人只吃伤害，或者只吃按比例缩短的控制。

### 3.4 挡路链路的处理

- `Enemy.checkBlocking`、`blockingTowerByCell` 这些代码**保留**，因为放置测试用的 `probe` 桩塔（`test-tower-placement-drag.js`）还依赖这条链路，但现役塔里不再有任何一座会触发它。
- `js/glyph/mountain.js` 顶部的注释改为新的定位说明。
- 征服模式 `waves.js` 第 33 行 `if (tower.onPath) tower.onPath = false;` 现在对山已经没用了，可以保留作为兜底。

### 3.5 图鉴与文案

- `CODEX.towers.mountain.role` 改成「石刺镇妖，压制异能」，普攻、大招两条说明同步更新，再加一条 `{ kind: '被动', name: '镇', … }`。图鉴页面要能渲染「被动」这一类招式（如果现在只支持普攻、大招两类，就补上）。
- `AGENTS.md` 的「当前玩法」段落里，删掉「山是唯一路径塔（有生命、挡路）」，改写为新的定位；`docs/architecture/current-structure.md` 如果有相同的描述也一起改。

## 5. 实施步骤

1. 修改配置，删除 `onPath` 和 `hp`。
2. 修改 `mountain.js`：删除回血，接入「镇」光环，控制效果改为调用 `ControlRules`（12 还没完成时先直接调用 `knockback` / `glyphStun`，留一个 TODO）。
3. 修改图鉴和文档文案。
4. 修改测试：把「山是唯一路径塔」改为「没有任何现役塔是路径塔」；新增断言「山不能放在路径格上、可以放在可建造格上」；`test-fusion.js` 里拿山当素材的夹具，改成任意一座非融合塔。

## 6. 风险与注意

- 已经开局的存档不受影响，因为游戏没有局内存档。
- 融合校验 `fusion.js:51` 会比较 `onPath` 是否一致；山改完以后两边都是 `false`，校验结果不变。
