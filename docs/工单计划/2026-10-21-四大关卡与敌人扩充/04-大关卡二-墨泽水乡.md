# 04 大关卡二：墨泽·水乡（2-1 ～ 2-5）

- **所属模块**：关卡数据（新增 `js/data/levels/part-02.js`，并加载到 `index.html` 和 `tests/test-level-curve.js`）
- **依赖**：01、08（鲛、蛙、龟）、09（夜叉、白骨精）、10（翻江倒海）

## 1. 目标

引入**双路径**和**隐身 / 跳跃类敌人**，让玩家学会两件事：① 布置范围伤害和地面效果来对付打不中的单位；② 兼顾两个入口。关底首领克制水、雷组合，逼玩家换思路。

## 2. 主题设定

- 水乡烟雨：芦苇、石桥、乌篷船。路径画成浅靛色的水道质感（如果现在的路径绘制支持主题色，就传入 `pathTint`；不支持的话，这一项延后，记进完成报告）。
- 本主题新出现的敌人：**鲛、蛙、龟**；精英：夜叉、**白骨精**；首领：**翻江倒海**。

## 5. 验收标准

- [ ] 双路径关卡的两条路径都能刷怪，而且分别以 A、B 指定的精英会走对应的路径。
- [ ] 2-5 的首领只走路径 A。
- [ ] 路径校验通过（双路径关卡允许路径之间共用格子，但每条路径自身连续、不自我交叉）。
- [ ] 2-1 中，开局只放火星类单体塔时，明显漏掉潜行中的鲛；加入一座土或木后漏怪明显减少（手工试玩记录到完成报告里）。
