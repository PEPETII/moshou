# 05 大关卡三：铁砚·关隘（3-1 ～ 3-5）

- **所属模块**：关卡数据（新增 `js/data/levels/part-03.js`）
- **依赖**：01、08（铠、骑、巫）、09（傀儡、镇墓兽）、10（铜墙铁壁）

## 1. 目标

主题是**重甲与地形限制**。用岩石格（`specialTerrain`，不能建造）压缩建塔空间，逼玩家在有限的位置里做取舍；敌人从「躲」变成「硬」，鼓励玩家使用金的破甲、弓、炮这些单发大伤害的塔，同时用骑、巫教玩家「先杀谁」。

## 2. 主题设定

- 山间关隘、栈道、铁砚碑。岩石格画成浓墨山石，用 `mapScenery.js` 的现有石块绘制；如果没有现成的，就用 `Brush` 画一个「石」字作为占位。
- 本主题新出现的敌人：**铠、骑、巫**；精英：**傀儡、镇墓兽**；首领：**铜墙铁壁**。

## 5. 验收标准

- [ ] 岩石格不能建塔，并在地图上可以看到；岩石格不和路径重叠。
- [ ] 3-2 可建造格数量在 60～75 之间，且全部位于第 1～4 行。
- [ ] 每关的精英、首领按时间点出现，并且双路径关卡里走的路径正确。
- [ ] 3-1 中，开局只放火、剑时，击杀铠的速度明显低于加入一座金之后（手工试玩，记录到完成报告里）。
