# 13 测试与验收

- **所属模块**：`tests/`、`package.json`、`scripts/`
- **依赖**：所有工单。建议每完成一份工单，就补上那份工单对应的测试，不要全部留到最后再写。

## 1. 目标

每条规则都能用 Node 测试自动验证。手工试玩只用来检查爽感和难度，不用来检查规则对不对。

- 测试环境照抄 `tests/helpers/glyph-env.js` 的写法，用 `vm` 加载真实配置和代码，不复制数值。新增的 JS 文件都要加进这个环境的加载列表。
- 随机相关的断言（权重分布、出场路径分布）要固定随机种子：在测试环境里用一个可设种子的 `Math.random` 替换掉原生函数，例如 mulberry32。

## 3. 关键断言示例

```js
// 12：四字首领不能被潮卷入
const boss = spawn(g, 'baiguiyexing', { s: 300 });
castWaterWave(g, waterTower);
stepFor(g, 1.2);
check('首领未被卷入', boss.carried === null && boss.s >= 300);

// 12：卷入预算
for (let i = 0; i < 30; i++) spawn(g, 'corpse', { s: 280 + i });
const wave = castWaterWave(g, waterTower);
check('卷入体量 ≤ 14', wave.caught.reduce((a, e) => a + ControlRules.carryCost(e), 0) <= 14);

// 01：计时结束但首领还活着 → 进入决战，停止刷怪
g.holdLeft = 0.01; stepFor(g, 0.1);
check('进入决战', g.duel === true && !g.gameEnded);
const n = g.enemies.length; stepFor(g, 3);
check('决战停止普通刷怪', g.enemies.filter((e) => !e.summoned).length <= n);
```
