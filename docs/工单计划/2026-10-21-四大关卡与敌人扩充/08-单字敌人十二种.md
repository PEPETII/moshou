# 08 单字敌人十二种

- **所属模块**：敌人配置（新增 `js/config/enemies-single.js`）、敌人能力（`js/entities/enemy/abilities/minor-a.js`、`minor-b.js`）、图鉴文案
- **依赖**：07（能力框架）、12（控制分档）

## 1. 目标

12 种单字敌人，每个大关卡引入 3 种。每种只有**一个**鲜明的能力，并且至少有**一种塔能明显克制它**，引导玩家调整阵容，而不是一套阵容打全程。

## 2. 设计原则

- 小怪是爽感来源：血量低、数量多、死得快。能力只改变「怎么打」，不当血包。
- 会影响塔的能力只有 3 种（蛛、魇，以及首领），而且都有持续时间、同塔冷却和数量上限（见每条的「上限」）。
- 所有冷却按 `dt × abilityTimeScale` 计时，会被山的「镇」减慢（02）。

## 4. 能力规格

### 4.1 骨 · 复聚（`reassemble`）
- 血量归零时，如果 `lastHitKind` 不在 `breakKinds`（`fire`、`thunder`、`yan`、`fen`）里，并且这次是第一次死：原地留下一堆碎骨 `delay = 1.5` 秒，碎骨期间不能被锁定，也不会被伤害；然后以 `hpRatio = 0.4` 的血量复活，继续往前走。
- 被火系或雷杀死时**直接碎掉**，弹出「碎」字飘字，给玩家明确的反馈。
- 第一次死亡**不给**奖励；真正死亡时给全额奖励。
- 上限：每只骨只复聚 1 次。

### 4.2 狐 · 幻步（`blink`）
- 每 `every = 3.5` 秒，沿路向前瞬移 `distance = 60` px（乘 `GLYPH_SCALE`），瞬移后 0.2 秒内免疫伤害；原地留下一个淡淡的狐影残像，0.4 秒后消失。
- 眩晕、冻结、被卷入期间不触发（07 的「能力冻结」规则）。
- 不会瞬移到超过核心的位置：最多到 `track.total - 20`。

### 4.3 蛛 · 缚丝（`web`）
- 每 `every = 5` 秒，找 `range = 150` px 内最近的一座塔，吐丝 0.4 秒后命中，这座塔进入「缚丝」状态 `duration = 2.5` 秒：所有笔画的写回时间 × `rewriteMul = 1.6`。
- 塔的表现：塔身罩一层灰白蛛网纹理，写回进度条变成灰色。
- **上限**：同一座塔在缚丝结束后 4 秒内不能再被缚；全场同时处于缚丝状态的塔最多 `maxWebbed = 3` 座。
- 塔侧实现：`Tower` 新增 `webT` 字段，`GlyphTower.consume` 计算写回时长时乘上缚丝倍率。

### 4.4 鲛 · 潜行（`dive`）+ 天生湿身
- 每 `every = 4` 秒潜入墨中 `duration = 1.5` 秒：`untargetable = true`，只露出一圈水纹；范围效果照常生效（07 §3.5）。
- 始终处于湿身状态（`makeWet` 每帧刷新）：雷对它造成 ×1.5 伤害，并且电弧跳跃不衰减（雷现有的规则）。湿身的减速效果对鲛**不生效**（它是水生的），所以用字段 `wetNoSlow: true` 标记。

### 4.5 蛙 · 跳跃（`hop`）
- 移动方式改为跳跃：每 `every = 1.6` 秒跳一次，0.4 秒内前进 `distance = 72` px；落地时停顿 0.3 秒。按这个节奏算，平均速度约 52 px/s，配置里的 `speedPx` 只作为落地后的爬行速度。
- 空中时：不吃地面效果（焦土、木苗、藤蔓、壁垒的减速和伤害、箭雨），不会被潮卷入，单体攻击照常可以命中。
- 被眩晕、冻结时落回地面。

### 4.6 龟 · 缩壳（`shell`）
- 血量第一次跌破 50% 时缩壳 `duration = 3` 秒：停止移动，受到的伤害 × `reduction = 0.25`（减伤 75%）。
- 灼烧伤害（`kind` 为灼烧 tick）**不受**减伤影响；处于破甲状态时，缩壳时长减半。
- 每只龟只缩壳 1 次。

### 4.7 铠 · 硬甲（`plating`）
- 每次受到伤害都先减去 `flat = 4` 点，最少保留 1 点。
- 持续伤害（灼烧、焦土、木苗、藤蔓、旋风的每一跳）只减 `dotFlat = 2` 点，避免持续伤害完全打不动它。
- 处于金的破甲状态时，硬甲失效。
- 克制关系：火星单发 9～14、剑气 11～15 吃亏明显；弓 26～32、炮弹 20～26 几乎不受影响。

### 4.8 骑 · 冲锋（`charge`）
- 每 `every = 6` 秒冲锋 `duration = 2` 秒，速度 × `speedMul = 2.2`，身后拖出墨痕。
- 以下情况会**打断冲锋**，并让下次冲锋的冷却重新计时：受到击退、眩晕、冻结，或者当前减速比例 ≥ 0.4。

### 4.9 巫 · 治疗（`heal`）
- 每 `every = 2.5` 秒，治疗 `radius = 100` px 内其它敌人各自最大血量的 `ratio = 8%`（不治疗自己，也不治疗首领），被治疗的敌人身上冒出淡绿色墨点。
- **上限**：同一个目标 2.5 秒内只能被治疗一次，多只巫不叠加；治疗多字敌人时，只治疗当前段。

### 4.10 魇 · 梦魇（`dread`）
- 常驻光环 `radius = 130` px：光环内的塔蓄力速度 × `chargeMul = 0.5`，`chargePerSec` 和 `chargePerHit` 都受影响。
- 塔的表现：圆相蓄力环变成暗紫色。
- **上限**：多只魇不叠加；光环不影响合字塔的普攻。

### 4.11 瘴 · 瘴雾（`miasma`）
- 周身 `radius = 80` px 的瘴雾：雾里的**其它**敌人受到的伤害 × `reduction = 0.75`，不叠加，瘴自己不受雾的保护。
- 风的普攻「风刃」命中瘴时，吹散瘴雾 `clearTime = 3` 秒；风的「旋」覆盖到瘴时，瘴雾全程消失。
- 瘴雾的减伤要计入 12 的增伤叠乘：它和其它减伤相乘，最低不低于 0.6。

### 4.12 饕 · 吞噬（`devour`）
- 每 `every = 3` 秒，吞掉前方 `radius = 50` px 内的一只尸或鬼：被吞的敌人直接消失，不给奖励；饕获得被吞者最大血量 60% 的最大血量和当前血量，体型变大 6%。
- **上限**：最大血量不超过基础值的 `maxMul = 3` 倍；每吞一只，饕被击杀时的奖励 +2。
- 克制关系：要尽早集火；弓会优先射血量最高的敌人，正好会选中它。

## 5. 绘制

- 每种敌人用书法字体画字，配色写进 `CONFIG.COLORS.enemies`（不能写死在绘制代码里）。建议色系：骨 骨白灰、狐 赭、蛛 灰黑、鲛 靛、蛙 青绿、龟 苔绿、铠 铁灰、骑 枣红、巫 墨绿、魇 暗紫、瘴 黄褐、饕 深赭。
- 带能力的敌人在能力即将触发前 0.3 秒给出前摇提示（字身轻微抖动或发光），让玩家有反应时间。

## 6. 涉及文件

新增 `js/config/enemies-single.js`、`js/entities/enemy/abilities/minor-a.js`（骨、狐、蛛、鲛、蛙、龟）、`minor-b.js`（铠、骑、巫、魇、瘴、饕）；修改 `js/glyph/glyph-tower.js`（缚丝、梦魇）、`js/glyph/wind.js`（吹散瘴雾）、`js/config/codex.js`、`js/config/domain-03.js`（只改颜色）。

## 7. 实施步骤

1. 写配置（按 00 §4 的加载顺序）。
2. 按顺序实现能力：骨 → 狐 → 鲛 → 蛙 → 龟 → 铠 → 骑 → 巫 → 瘴 → 饕 → 蛛 → 魇。会影响塔的能力放到最后做。
3. 塔侧加接口：缚丝、梦魇、吹散瘴雾。
4. 补全图鉴文案。

## 8. 验收标准（每种敌人都有一条自动化断言，见 13）

- [ ] 骨：被水杀死后会复聚，以 40% 血量复活；被火杀死不复聚；每只只复聚一次。
- [ ] 狐：每 3.5 秒前进 60 × S px；被眩晕时不瞬移。
- [ ] 蛛：被缚的塔写回时间 ×1.6；同塔 4 秒内不会被重复缚；全场同时被缚的塔不超过 3 座。
- [ ] 鲛：潜行时不会被火星锁定，但会被焦土伤害；雷对它 ×1.5。
- [ ] 蛙：在空中时不吃木苗伤害。
- [ ] 龟：缩壳期间受到 100 点非灼烧伤害只掉 25 点血；灼烧伤害不打折。
- [ ] 铠：一次 10 点伤害实际只扣 6 点；处于破甲状态时扣 10 × 1.35 点。
- [ ] 骑：冲锋时被击退，冲锋立即结束。
- [ ] 巫：两只巫同时治疗同一个目标，2.5 秒内只生效一次。
- [ ] 魇：光环内的塔蓄力速度减半；两只魇的效果不叠加。
- [ ] 瘴：瘴雾内的敌人受伤 ×0.75；被风刃命中后瘴雾消失 3 秒。
- [ ] 饕：吞掉一只尸后，最大血量 +24（尸 40 × 0.6）；最大血量不超过 330。
