# 工单：修正「火」字字形（点钝化 / 断开右点 / 错落起笔）

- 日期：2026-10-17
- 类型：原型字形数据修正（承接「字形弹道交互原型」）
- 状态：进行中

## 1. 任务目标

修正 `demo/glyph-demo-data.js` 中「火」字的四笔坐标与笔压，使其在静态与 50px 塔身尺寸下都能读出「火」，而不是「人 + 两点」。

## 2. 当前问题 / 背景

用户反馈原型中的「火」不像火。经比对实际数据，确认三处硬缺陷：

1. **点过重**：左点笔压峰值 11，高于长撇主笔的 10，点抢了主笔的分量。
2. **点被写成撇**：四笔收笔宽度均为 3（一律出锋成尖），点失去「钝头」，点与撇失去质感差。
3. **右撇与右点相衔**：右撇收笔 (76,66)、方向 65°，右点起笔 (79,71)、方向 56°，净距仅 5.8 单位，视觉上合成一条「带钩的腿」。
4. **顶部成尖角**：两笔起笔仅错开 (4,4)，顶出尖锐「∧」，形似「人」的头部。

叠加渲染层问题：50px 塔身下飞白按比例作用于所有笔画，最短的点最先被断笔吃掉，只剩两条主干。

## 3. 涉及文件

| 文件 | 改动 |
| --- | --- |
| `demo/glyph-demo-data.js` | 替换「火」的四笔坐标与笔压；两点加 `noDry` 标记 |
| `demo/glyph-demo-ink.js` | `paintGlyph` 支持笔画级 `noDry`（该笔不参与飞白） |
| `demo/glyph-demo-engine.js` | 塔身逐笔重绘的三处 `Ink.ribbon` 调用尊重 `noDry` |
| `demo/glyph-demo-app.js` | 字形解剖面板同样尊重 `noDry` |

## 4. 实施步骤

1. 建立工单（本文件）。
2. 按「点要钝 / 两笔要错落 / 右点要断开」三条规则替换坐标。
3. 渲染层加入笔画级 `noDry`：点的 `dryMul = 0`。
4. 用 Playwright 截取修正前后的字形解剖面板与塔身做对比。
5. 复核塔身可读性与控制台报错，写完成报告。

## 5. 风险与注意事项

- 点的收笔宽度改为 9 后，短笔画可能渲染成墨团；需在 50px 与 264px 两个尺寸下分别确认形还算不算「点」。
- 右点下移后靠近字身边缘 (x=90)，需确认不会被裁切。
- 只改字形数据与飞白开关，**不得**改动弹道逻辑与命中判定，四塔行为应保持完全一致。

## 6. 验收标准

1. 字形解剖面板中的「火」呈现「人字形两笔 + 左点右点」的四笔分立结构，点明显钝于撇。
2. 50px 塔身下仍能分辨两个点，不再退化成「人」。
3. 两点在任意尺寸下均无飞白断笔。
4. 控制台无报错；`npm run check:line-count` 通过。
5. 弹道、伤害、笔顺时序与修正前一致。
