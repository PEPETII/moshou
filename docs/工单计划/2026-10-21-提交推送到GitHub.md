## 风险与注意事项

- **不可逆性**：推送是对外可见动作，远程 history 一旦写入难以回收；本批次为常规
  快进推送，无 amend / force，不重写历史。
- **依赖完整性**：`index.html` 的脚本加载顺序与新增配置文件必须一并提交，否则
  远程直接打开页面会因缺模块而白屏。已在步骤 1 由测试与语法检查覆盖。
- **产物文件**：`docs/test-results/balance-sheet.md` 为 `npm run balance:sheet`
  生成结果，属项目跟踪的基线记录，随批次提交。
- **不含敏感信息**：本次变更无密钥、无本地绝对路径外泄；`node_modules` 被忽略。

## 验收标准
