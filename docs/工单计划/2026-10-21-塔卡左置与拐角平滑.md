# 塔卡栏左置 + 拐角路径平滑

## 任务目标
1. 塔防塔卡栏从画布右缘移到左缘，一行一张卡，便于手机横屏左手选塔。
2. 敌人过拐角时沿圆弧转向，消除直角折转与车道（lane）偏移在拐点处的瞬跳、叠团。

## 当前问题/背景
- 塔卡在右侧 dock，4 座起压成 2×2 小卡；十二座塔拥挤。
- `PathTrack` 为纯折线，拐点处朝向瞬变，`lane` 偏移沿法线瞬间翻转，敌人在拐角叠成一团。

## 涉及文件
- `js/bootstrap/page-markup.js`（塔卡 DOM 拆成左 dock）
- `css/ink-ui/battle-layout.css`（左 dock、单列卡、右 dock 仅保留停与战况）
- `js/game.js`（镜头 insetLeft + insetRight）
- `js/core/path-track.js`、`js/config/domain-01.js`（圆角半径配置）
- `tests/test-path-track.js`（拐角断言改为圆弧口径）

## 实施步骤
1. 新增左 dock 容纳 `#bottom-bar`；右 dock 保留暂停与战况；镜头两侧都留 dock 宽余量。
2. 卡片单列、可纵向滚动；拖出到右侧放塔（手势已按纵轴判定）。
3. `PathTrack.fromCells` 对每个拐点用二次贝塞尔倒圆角并折成短线段；`cellS` 按圆弧上最近里程重算。
4. 更新测试，跑 `npm test` 与相关用例，浏览器实测。

## 风险与注意事项
- 里程总长因圆角缩短；依赖 `cellS`/`cellIndexAt` 的山塔阻挡需保持正确。
- 征服模式为环形路径，同样受益，需验证回环接缝。
- 手机上卡片触控尺寸 ≥44px。

## 验收标准
- 塔卡在左侧单列，可滚动、可点选、可拖出放塔；右侧停/战况正常；镜头可滚到被遮格。
- 拐角处敌人沿弧过渡，无叠团；`npm test` 通过。
