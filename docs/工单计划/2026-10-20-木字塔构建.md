# 工单：构建「木」字炮塔（弹道接入）

- 日期：2026-10-20
- 类型：新塔 / 字形弹道扩展
- 前置确认：与火、水同构；本轮只要求"能在真实战斗中触发、发射、命中"，不做新机制、不做平衡调优。

## 一、任务目标

新增第四座字形塔「木」，四笔（横、竖、撇、捺）写出整字，具备与现有三塔一致的接口：按笔顺写回、圆相蓄力、蓄满自动大招、弹道分派、打击反馈。接入塔防底栏与征服召唤池，实战可开火命中。

## 二、当前问题 / 背景

`CONFIG.TOWERS.wood` 只有旧单字塔的遗留字段（damage 0.45 / range 4.0 / cooldown 380 / unlockLevel 2 / desc「快速连射」），没有笔画数据、没有 `GlyphWood`，`GlyphTower.impl()` 未登记。直接放进塔池会套用水塔招式并错色，属于静默错误。

## 三、玩法设计（本轮落地）

- 字形：四笔，笔顺 横 → 竖 → 撇 → 捺。
- 普攻「木刺」：撇笔化作木刺直线射出，路径上可贯穿至多 3 名敌人，每名受到 9–13 伤害并被轻推。与火的追踪、水的柱状、土的石片区分开。
- 大招「森」：四笔整字砸向射程内敌群最密处，落地炸开成一圈木刺，范围内敌人受 60 点（按距离衰减）伤害并被向外推开。沿用"掷字—落地—范围结算"的同构流程，不新增地面持续效果。
- 定位：中速穿透、无状态附加，纯物理输出型。

## 五、实施步骤

1. 配置：`GLYPHS.wood` 四笔；`GLYPH_COLORS` 木色；`GLYPH_MOVES_RAW.wood` + `PX_KEYS.wood`。
2. 实现 `GlyphWood.update / cast / updateShot / drawShot`，按火、土的既有结构组织。
3. 分派：`GlyphTower.impl()` 增加 wood 分支。
4. 接入：`ACTIVE_TOWERS`、`index.html`、图鉴文案与配色。
5. 测试：四笔笔顺、贯穿命中上限、蓄满自动释放、绘制不抛错；更新池子断言。
6. 实测：塔防 1-1 放置木塔观察木刺命中；征服 1-1 召唤木塔。

## 六、风险与注意事项

- `GlyphTower.impl()` 漏登记会让木塔静默套用水招，必须补断言。
- 贯穿需要按敌人去重（同一发木刺不得对同一敌人重复结算），用命中集合记录。
- 木刺是直线飞行，不做追踪；射速与贯穿数需保证在 1-1 的怪流中能稳定命中。
- 只新增配置项与 `wood.js`，不修改火、水、土任何参数或分支。

## 七、验收标准

1. 塔防底栏出现「木」卡，放置后四笔按序写出，写满撇笔后可射出木刺。
2. 木刺直线飞行，命中首个敌人后继续穿透，最多结算 3 个目标，同一敌人只结算一次。
3. 蓄满后自动释放「森」：整字落向敌群密集处，范围内敌人掉血并被推开。
4. 征服召唤池含木塔且可正常攻击。
5. 图鉴出现木塔条目，四笔序号与两式文案齐全，配色为木色。
6. `npm test` 全绿、行数检查通过、无页面报错。
