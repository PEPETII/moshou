# 工单：P2 图鉴横屏改版（图鉴主界面 · 炮塔志 · 妖异录）

- 日期：2026-10-19
- 上级方案：[全界面横屏适配与水墨视觉统一](2026-10-19-横屏适配与水墨视觉统一.md) 第 3.2 节「图鉴主界面」「炮塔志 / 妖异录」；问题编号 K1、K2、K3、A4、B1、B2、B4
- 依赖：[P1 水墨设计令牌与组件](2026-10-19-P1-水墨设计令牌与组件.md)（`.ink-page`、`.ink-split`、`.ink-item`、`.ink-stat` 等）

## 1. 任务目标

1. 图鉴主界面套用三段骨架：返回按钮在顶栏左上，两张入口卡占满内容区。在 360px 高的视口里，卡片和返回入口全部位于首屏，不需要滚动（K1）。
2. 炮塔志、妖异录改为**常驻双栏**（40 : 60），取消抽屉覆盖层。进入时默认选中第一项，右栏任何时候都不会只剩一句装饰文案（K2、A4）。
3. 列表项改为富信息行：印块、名称、一句定位、造价或血量标签（K2、B4）。
4. 炮塔详情加入**字形书写预览**：用 `CONFIG.GLYPHS` 的笔画数据，按笔顺写出整字，并显示笔顺名称；点击可以重写。
5. 导航统一：顶栏左上为「‹ 上一级」，右侧加「主菜单」直达入口（K3）。
6. 删除过时的筛选页签（B1）；标题统一使用入口名「炮塔志」「妖异录」（B2）；数值带单位和等级，例如「0.47 格/秒 · 常」（B4）。

## 2. 当前问题 / 背景（已核对代码）

- 页面结构：`js/bootstrap/page-markup.js:63-127`。详情面板是独立的 `#tower-detail-panel` / `#enemy-detail-panel`，覆盖在列表上。
- 逻辑：`js/ui/encyclopedia.js`（348 行），包含筛选、`getTowerCategory`（下架塔分类）、详情显示和隐藏。
- 样式分散在三处，并且互相覆盖：
  - `css/inline/part-02.css:30-505`：整段都是旧版图鉴（圆角、阴影、金棕色）
  - `css/ink-ui/pages.css:1-28, 226-345`，以及媒体查询里的图鉴部分
  - `css/ink-ui/mobile.css:49-86, 130-132`
- `css/ink-ui/foundation.css` 中的 `#main-menu button:not(.menu-btn)` 优先级是 (1,1,1)，会覆盖 `ink-` 组件（边框、背景、`::before` 被隐藏），需要把 `ink-` 组件排除在外。
- 敌人的 `speed` 是由 `speedPx` 换算出的「格/秒」（尸 0.47、鬼约 0.84、巨约 0.26）。
- 开发脚本 `scripts/mobile-check/run-screens.js`、`probe-dex.js` 引用了 `#close-*-detail` 和 `.filter-tabs`，需要同步更新。

## 4. 实施步骤

1. 新增 `js/config/codex.js`，写入塔、敌人的图鉴文案和速度分档。
2. 重写图鉴页面结构：三个容器保留原 ID（`menu.js`、`conquest.js` 会统一隐藏它们），加上 `ink-page` 类；保留 `btn-tower-encyclopedia`、`btn-enemy-encyclopedia`、`back-to-*` 等 ID。
3. 重写 `encyclopedia.js`：进入列表页时渲染列表并默认选中第一项；列表支持方向键切换（`role="listbox"`）。
4. 新增 `codex-glyph.js`：使用 `Brush.drawStroke` 并传入 `progress`，逐笔写出；书写中的笔画用元素色，写完的用墨色；画布按设备像素比放大；离开页面时停止动画。
5. 编写 `codex.css`，删除三处旧规则，并调整 `foundation.css` 的排除条件。
6. 更新开发脚本中的选择器。
7. 在横屏矩阵（640×360、740×360、844×390、932×430）中验证，再用桌面尺寸和竖屏各验证一次；运行 `npm test`。

## 5. 风险与注意事项

- 删除 `inline/part-02.css` 第 30–505 行前，要确认这些类名没有被其他界面复用（已用 grep 核对：`.detail-*`、`.encyclopedia-*`、`.filter-tab` 只出现在图鉴中）。
- 动画只在页面可见时运行，离开时取消 `requestAnimationFrame`，避免后台空转。
- 文案只写配置里能核实的事实（血量、移速、撞核伤害），不虚构机制。
- 行数：`encyclopedia.js` 重写后要少于 300 行，新文件都要少于 600 行。
- 不改游戏数值，也不改战斗中的塔信息面板。

## 6. 验收标准

1. 在 640×360 到 932×430 的横屏矩阵中：图鉴主界面的两张卡和返回按钮都在首屏；炮塔志、妖异录的顶栏、列表、详情都在首屏，内容过长时只在各自的栏内滚动；页面整体没有横向或纵向溢出。
2. 进入炮塔志或妖异录时，第一项已经选中，右栏显示详情；点击其他项可以切换，选中项有朱砂竖印。
3. 炮塔详情能按笔顺写出「火」「水」，并高亮当前笔画名；点击预览可以重写；开启减少动效时直接显示整字。
4. 返回链路正确：炮塔志 → 图鉴 → 主菜单；「主菜单」按钮可以直接回到主菜单。
5. 所有可点元素不小于 44px；`check:tokens` 中新文件零违规。
6. `npm test` 全部通过。
