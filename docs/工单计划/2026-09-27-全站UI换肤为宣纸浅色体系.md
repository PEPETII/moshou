# 工单：路径改色 + 全站 UI（CSS 外壳）换肤为宣纸浅色体系

- 日期：2026-09-27
- 类型：视觉 / 主题配色（第二轮）
- 前置工单：`2026-09-27-画布配色由暗墨底切换为宣纸浅底.md`（已完成）

## 1. 任务目标

1. **路径颜色改为 `#8a8377`**。
2. **整个游戏的颜色同步修改** —— 上一工单只改了 Canvas 画布层，本次补齐 UI 外壳（`css/style`、`css/inline` 两套共 10 个文件，约 4100 行）以及 JS 中的内联 DOM 样式，消除「浅色画布嵌在深色页面中」的割裂。

## 2. 当前问题 / 背景

- 上一工单完成后，画布已是 `#f4efe4` 宣纸底，但页面 `body` 仍是 `#0c0c0c`、文字仍是 `#f5f5f5`，明暗割裂。
- CSS 中颜色**全部为硬编码**，无 CSS 变量层（`--z-*`、`--ui-scale` 等非颜色变量除外），因此只能逐值替换。
- 颜色分布（css/style）：`#1a1a1a`×22、`#2d2d2d`×20、`#3a3a3a`×19、`#e8e8e8`×17、`#1f1f1f`×14、`#666`×13、`#c45c48`×10、`#2a2a2a`×9、`#4a4a4a`×8、`#141414`×8、`#d4d4d4`×7。css/inline 分布相近。

## 6. 风险与注意事项

- **映射表无键值交集**，替换一次性完成，不会出现链式替换（已核验）。
- 短色值 `#666`/`#000`/`#fff` 使用 `\b` 边界，避免误伤 `#ffffff` 等长值。
- `#c45c48` 朱砂保留，因此按钮 / 强调色外观不变，仅中性色换肤。
- CSS 无变量层，后续若再做主题切换建议先抽 CSS 变量（本工单不做重构，避免超范围）。
- 两套 CSS（style / inline）内容高度重合且均被 `index.html` 引用，必须同步替换。
- 不得为规避行数限制压缩代码；本工单仅替换颜色字面量，不改结构。
