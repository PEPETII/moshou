# 工单 06：打击反馈与设置项

- 总览：[00-总览](00-总览.md)（对应决策 D9，假设 A6）
- 依赖：05

## 任务目标

1. 移植原型的打击反馈：伤害数字、灼烧数字合并、顿帧、震屏、碎字、墨渍、焦痕、冲击环、连斩，以及朱印（一气呵成 / 势如破竹 / 所向披靡）。
2. 「设置」页新增「打击反馈 · 开 / 关」，**默认开**，刷新后记住上次的选择。
3. 和现有的「墨迹动效」设置、系统「减少动态效果」联动：动效被减少时，**不震屏**。

## 当前问题/背景

- 原型 `js/fx.js` 的 `FX` 对象：粒子、数字、`shake`、`hitstop`、墨渍层（离屏画布，每 0.5 秒褪色 3.5%）、`bestCombo` 和连斩、朱印。开关 `FX.feedback` 关掉的是：数字、顿帧、震屏、碎字、墨渍、连斩。`FX.reduceMotion` 只关震屏。
- 正式游戏已有：`js/particle.js`（`ParticleSystem`）、`CONFIG.GAMEPLAY.shakeDuration`（150ms）和敌人自身的抖动（`js/entities/enemy/combat.js:148`）、`js/inkRenderer.js` 的水墨特效。
- 现有设置页：`js/bootstrap/page-markup.js:31-46`（`#settings-container`：墨迹动效、音效、音乐）。「墨迹动效」的逻辑在 `js/ui/ink-interactions.js`，存储键是 `moshou-ink-motion`，取值 `full` / `reduced`，写入 `document.documentElement.dataset.inkMotion`。

## 涉及文件

- 新建 `js/glyph/fx.js`：移植原型 `FX`，命名为 `GlyphFX`，避免和现有对象重名；墨渍层按**世界尺寸**创建（1872×432 或 1584×432）
- `js/config/glyph-battle.js`：反馈参数集中配置，包括顿帧时长、震屏强度、数字字号、`COMBO_MARKS`、墨渍褪色速率
- `js/bootstrap/page-markup.js`：在 `#settings-container` 的「墨迹动效」按钮下面加 `<button id="hit-feedback-toggle" type="button" aria-pressed="true">打击反馈 · 开</button>`，再加一行说明文字
- `js/ui/ink-interactions.js`，或新建 `js/ui/settings-feedback.js`（推荐，单一职责）：开关读写 `localStorage['moshou_hit_feedback']`，缺省为 `'on'`；同步 `GlyphFX.feedback`
- `js/game.js`、`js/conquestGame.js`：主循环接入顿帧（`hitstop > 0` 时，这一帧的游戏时间 × 0.06）；绘制世界层前叠加震屏偏移；HUD 层绘制连斩和朱印，不随震屏晃动
- `js/core/rendering.js`、`js/modes/conquest/rendering.js`：插入墨渍层（世界层，放在背景之上、敌人之下）、伤害数字层、HUD 连斩层
- `js/glyph/fire.js`、`js/glyph/water.js`、敌人死亡逻辑：把 05 预留的 `GlyphFX.kill(enemy, kind)` 等调用点接通；火杀的墨渍偏焦褐，水杀偏靛青
- `index.html`：引入新脚本
- `css/ink-ui/*`：新按钮沿用设置页现有的按钮样式，不新增风格

## 实施步骤

1. **移植 `FX`**：照搬原型逻辑，替换全局依赖：`COLORS` 改读 `CONFIG.COLORS` 或 `glyph-battle` 配置，`FONT_BRUSH` 改读 `CONFIG.FONTS.BRUSH`。
2. **开关语义**（和原型一致）：
   - `feedback = false`：不显示伤害数字，不顿帧、不震屏，不出碎字和墨渍，不计连斩，不盖朱印；**弹道和招式本身的表现保留**，比如火星、焚的火字、浪头；
   - `reduceMotion = true`：只关震屏。这里的 `reduceMotion` 取 `dataset.inkMotion === 'reduced'` 和 `matchMedia('(prefers-reduced-motion: reduce)')` 两者之一为真即可。
3. **设置持久化**：开关切换后立即写入 `localStorage`，并更新按钮文字和 `aria-pressed`。战斗中途在设置里切换时，即时生效（`GlyphFX.feedback` 每帧读取一次）。`localStorage` 不可用时退回默认值「开」，不报错。
4. **顿帧与倍速、暂停**：顿帧按「游戏时间」递减，不按真实时间；暂停时冻结；如果正式游戏有倍速，倍速乘在顿帧缩放之前。**多座塔同时触发时，顿帧取最大值而不是累加**；原型 `addHitstop` 如果是累加，要改成 `max`，并设上限 0.12 秒。
5. **震屏**：上限 22（原型值）× `GLYPH_SCALE`；只平移世界层，镜头本身的 `x` 不受影响，避免干扰放置判定。
6. **和现有特效的关系**：火、水不再触发旧管线的命中粒子和敌人受击抖动；只保留新反馈，避免两套重叠。下架塔的旧特效不动。
7. **墨渍层**：开局时清空；关卡结束、退出时释放画布引用。焚的焦痕按 22% 透明度印进墨渍层。
8. **自测**：
   - 首次进入时开关显示「开」，战斗中能看到数字、顿帧、震屏、碎字、墨渍和连斩；
   - 关掉后刷新页面，仍是「关」，战斗中以上反馈全部消失，招式表现仍在；
   - 「墨迹动效」关闭后，反馈仍开但不震屏；
   - 「潮」档满屏时，伤害数字不刷屏（灼烧每 0.45 秒合并一次）；手机横屏帧率不低于 45fps。

## 风险与注意事项

- 260 只敌人的同屏伤害数字可能很多。如果帧率不达标，先限制同屏数字上限（例如 80 个，超出就丢弃最旧的），并写进报告。
- 墨渍层是世界尺寸的离屏画布，每 0.5 秒做一次整体褪色（`globalCompositeOperation` 加填充），开销和画布面积成正比；DPR 最高按 2 计算。
- 连斩和朱印画在 HUD 层，要避开征服模式右上角的「危险 n / 200」和塔防的坚守倒计时。
- 不要改动现有「墨迹动效」按钮的行为和存储键。

## 验收标准

- 设置页有「打击反馈」开关，默认开，刷新后保持选择。
- 开关语义和原型一致；「减少动效」时不震屏。
- 顿帧不叠加失控，暂停时不推进。
- `npm test` 通过；已写完成报告，附开、关两种状态的对比截图。
