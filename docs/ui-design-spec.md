## 一、设计原则

### 1. 水墨一致性

所有 UI 元素必须遵循水墨视觉语言。禁止引入与水墨风格冲突的视觉元素（如渐变彩条、拟物高光、扁平色块）。界面元素以黑、灰、白为主色调，朱砂红 `#c45c48` 是唯一允许的彩色强调色，仅用于核心/危险/关键信息。

### 2. 信息层级分明

采用"浓淡墨"三层信息架构：
- **浓墨层**（最暗背景 `#0c0c0c`～`#141414`）：承载容器与底板
- **淡墨层**（中灰 `#1a1a1a`～`#2d2d2d`）：承载交互元素（按钮、卡片、输入框）
- **飞白层**（亮灰～白 `#8a8a8a`～`#f5f5f5`）：承载文字与高亮信息

信息优先级：核心状态 > 操作按钮 > 辅助说明 > 装饰元素。

### 3. 触控优先

所有可交互元素最小触控区域 44 × 44px（符合 Apple HIG 与 Material 标准）。间距需保证手指不误触相邻目标。悬停状态仅作桌面端增强，移动端依赖 `:active` 反馈。

### 4. 克制用色

水墨画的精髓在于"留白"与"墨分五色"。UI 中避免大面积纯色填充，使用半透明、渐变边缘、`inset` 内阴影模拟宣纸渗透效果。彩色仅用于语义标记（朱砂红 = 危险/核心，金色 = 货币/奖励）。

### 5. 书法字体层级

毛笔字体（Ma Shan Zheng）用于标题、炮塔文字、数值等需要视觉冲击的场景；宋体（ZCOOL XiaoWei）用于正文、标签、说明等需要可读性的场景。两者不可混用于同一信息单元。

### 2.5 深色/浅色模式

当前仅支持深色模式（水墨风格天然适配深色）。浅色模式暂不实现，预留以下设计方向：

- 浅色模式底色：宣纸色 `#f5f0e8`
- 浅色模式文字：浓墨 `#1a1a1a`
- 浅色模式强调色：朱砂红保持不变
- 浅色模式面板：半透明宣纸纹理 `rgba(245, 240, 232, 0.9)`

### 3.3 字重规则

- **Ma Shan Zheng**：始终使用 `font-weight: normal`（该字体无粗体变体）
- **ZCOOL XiaoWei**：始终使用 `font-weight: normal`
- 需要强调时通过字号增大或颜色变亮实现，不依赖字重

### 3.4 数字显示规范

| 数据类型 | 格式 | 字体 | 示例 |
|---------|------|------|------|
| 金币 | 整数，无分隔符 | Ma Shan Zheng | `300` |
| HP/伤害 | 整数或一位小数 | Ma Shan Zheng | `18` / `1.5` |
| 攻速 | 一位小数 + "秒" | ZCOOL XiaoWei | `0.9秒` |
| 减速 | 百分比整数 | ZCOOL XiaoWei | `40%` |
| 范围 | 整数 + "格" | ZCOOL XiaoWei | `4格` |
| 波次 | 当前/总数 | Ma Shan Zheng | `0/3` |
| 核心HP | 当前/最大 | Ma Shan Zheng | `20/20` |

## 四、图标与图形规范

### 4.1 炮塔图标设计规则

本项目炮塔以**汉字字符**作为图标，不使用传统图形图标。

| 规则 | 说明 |
|-----|------|
| 识别度 | 每种炮塔用1个汉字表示（火/水/山/木/金/土），多字炮塔竖排2行（心中/炎、如风/似真） |
| 字符尺寸 | 单字：32px Ma Shan Zheng；多字：16px Ma Shan Zheng，`line-height: 1.3` |
| 颜色 | 默认 `#e8e8e8`，锁定态 `opacity: 0.35` |
| 背景 | 淡墨卡片 `#1a1a1a`，2px 实线边框 `#2d2d2d` |
| 选中态 | 边框 `#5a5a5a`（桌面）/ `#ffd700`（移动端），背景 `#242424` |

[配图：炮塔选择项各状态对比——默认/悬浮/选中/锁定]

### 4.2 敌人图标设计规则

| 规则 | 说明 |
|-----|------|
| 识别度 | 每种敌人用1个汉字表示（尸/鬼/甲/分/铁/速等），多字敌人竖排（巨尸/超巨尸/始终霸王） |

> 注意：当前版本资源显示为纯文字，后续扩展可增加小型汉字图标（如"金"字作为金币图标）。

### 5.4 按钮文字规范

- 字体：Ma Shan Zheng（主要按钮）/ ZCOOL XiaoWei（次要按钮）
- 字间距：主要按钮 `letter-spacing: 2px`～`6px`，操作按钮 `2px`
- 文字内容：简洁中文，不超过4字（"升级"、"出售"、"波次"、"确定"）
- 禁用态文字：描述原因（"融合不可升级"、"已满级"）或附加费用（"升级 120金"）

### 6.4 面板布局规则

信息排列优先级（从上到下）：
1. 标题/字符标识
2. 核心数值（等级、伤害、范围）
3. 次要数值（攻速、减速、特殊效果）

## 十二、响应式适配规则

### 12.1 基准设计尺寸

| 参数 | 值 | 说明 |
|-----|---|------|
| 游戏区域 | 800 × 480px | Canvas 800 × 432 + 顶部栏 48 |

### 12.2 缩放算法

```
scale = min(
  (viewportWidth - padding*2) / totalWidth,
  (viewportHeight - padding*2) / totalHeight,
  1  // 不放大
)
```

- `padding = 20px`
- `transform-origin: center center`
- `transition: transform 0.1s ease-out`

### 12.3 不同屏幕比例的适配策略

| 屏幕比例 | 策略 | 说明 |
|---------|------|------|
| 16:9（标准横屏） | 完美适配 | 基准设计比例 |
| 18:9 / 19.5:9（长屏手机） | 两侧留黑边 | 缩放后水平居中 |
| 4:3（iPad） | 上下留黑边 | 缩放后垂直居中 |
| 超小屏幕（<360px 宽） | 最大缩放至可视 | 可能需要隐藏左侧面板 |

### 12.4 横竖屏处理方案

| 状态 | 处理 |
|-----|------|
| 横屏 | 正常显示游戏 |
| 竖屏 | 显示旋转提示遮罩（`body.show-rotate-tip`） |
| 旋转动画 | 手机图标 ±30° 旋转，1.5s 循环 |
| 旋转提示文字 | "请旋转至横屏"，Ma Shan Zheng 24px，`#888` |
| 旋转回横屏 | 延迟 100ms 后重新计算缩放 |
