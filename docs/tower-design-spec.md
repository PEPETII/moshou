## 一、设计总则

### 1.1 设计约束

| 约束项 | 规则 | 说明 |
|--------|------|------|
| 命名 | 1～4个汉字，诗意/武道意象 | 与现有"心中炎""如风似真"风格一致 |
| 费用区间 | 80～350金 | 低端辅助80～120，中端攻击130～220，高端专精230～350 |
| DPS效率 | 0.008～0.015 | `DPS / cost`，纯辅助型不计DPS |
| 最大等级 | 3级 | 升级费用 = `upgradeCost × currentLevel` |
| 出售回收 | 总投入 × 70% | 与现有系统一致 |
| 攻击冷却 | 100ms～5000ms | 低于100ms影响性能，高于5s体验差 |
| 攻击范围 | 1～10格 | 1格=48px，10格≈屏幕宽 |
| 视觉风格 | 水墨色板，汉字渲染 | 遵循 `CONFIG.COLORS` 色板，朱砂红仅用于核心/危险 |

### 1.2 新炮塔分类体系

| 类别 | 数量 | 定位 | 设计思路 |
|------|------|------|---------|
| 元素攻击型 | 8 | 输出伤害 | 引入雷/冰/毒/风/光/暗/星/霜新元素，扩展克制体系 |
| 战术辅助型 | 8 | 增益/减益 | 填补现有系统缺少的增益光环、标记、眩晕等辅助机制 |
| 防御工事型 | 6 | 阻挡/陷阱 | 扩展路径放置型炮塔，丰富阻挡和陷阱策略 |
| 特殊机制型 | 8 | 独特玩法 | 产金、治疗、召唤、自爆等突破常规的机制 |

### 1.3 新元素交互设计

在现有火标记+蒸发（火→水）体系基础上，新增以下元素交互链：

```
雷 → 导电：命中灼烧/潮湿敌人时伤害×1.5
冰 → 冻结：对已减速敌人施加"冰冻"（完全定身1s）
毒 → 腐蚀：叠加3层后触发"溃烂"（护甲归零5s）
风 → 吹散：清除敌人正面增益（护甲/隐身）
光 → 净化：使隐身敌人显形4s
暗 → 吞噬：击杀敌人回复核心1点HP
霜 → 深寒：对冰冻状态敌人伤害×2
星 → 流转：随机获得一种元素效果
```

| 项目 | 内容 |

| **名称** | 雷 |
| **类型** | 元素攻击型 — 穿透连锁 |
| **核心功能** | 发射雷电弹，命中后跳跃至附近敌人，对灼烧/潮湿敌人伤害加成 |
| **解锁关卡** | 第4关 |

**基础属性：**

| 属性 | 数值 |
|------|------|
| 建造费用 | 200金 |
| 攻击力 | 2.0 |
| 攻击范围 | 5格 |
| 攻击冷却 | 1400ms |
| 升级基础费用 | 100金 |
| 最大等级 | 3 |

**特殊技能 — 导电弹射：**

| 效果 | 数值 |
|------|------|
| 弹射次数 | 3次 |
| 弹射范围 | 180px |
| 弹射伤害衰减 | 每次递减25% |
| 导电加成 | 命中灼烧/潮湿敌人时伤害×1.5 |

**适用场景分析：**

- 敌人密集排列时效果最佳，弹射可覆盖4个目标
- 与火塔/水塔形成元素联动：先火灼烧或先水潮湿，再雷触发导电加成
- 对护甲敌人（甲/铁）有效，弹射伤害无视护甲衰减
- 不适合对抗分散或隐身敌人

### 2.7 【星】字炮塔

| 项目 | 内容 |
|------|------|
| **名称** | 星 |
| **类型** | 元素攻击型 — 随机流转 |
| **核心功能** | 每次攻击随机获得一种元素效果（火灼烧/水减速/雷弹射/冰冻结），不可预测但上限高 |
| **解锁关卡** | 第8关 |

**基础属性：**

| 属性 | 数值 |
|------|------|
| 建造费用 | 260金 |
| 攻击力 | 1.8 |
| 攻击范围 | 5格 |
| 攻击冷却 | 1000ms |
| 升级基础费用 | 130金 |
| 最大等级 | 3 |

**特殊技能 — 星辰流转：**

| 效果 | 数值 |
|------|------|
| 元素随机 | 每次攻击随机：火(30%)/水(25%)/雷(20%)/冰(25%) |
| 火效果 | 灼烧1.5s，0.8伤害/秒 |
| 水效果 | 减速30%，持续2s |
| 雷效果 | 弹射1次，50%伤害 |
| 冰效果 | 减速20%+5%概率冻结1s |
| 连击 | 连续触发同元素时效果+30% |

**适用场景分析：**

- 万金油炮塔，适合不确定敌人类型的局面
- 随机性带来不确定性，赌狗最爱但不宜作为唯一输出
- 连击机制鼓励多座星塔集中放置，提高同元素连击概率
- 高费用高风险高回报，适合中后期经济宽裕时建造

**升级路线：**

|------|--------|------|------|---------|---------|---------|
