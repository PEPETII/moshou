## 3. 发现的问题

### 问题 #1: 塔防模式返回按钮可访问性问题

**问题ID**: BTN-ISSUE-001  
**严重级别**: P2 - 一般  
**所属模块**: 塔防模式 - 游戏界面  
**发现时间**: 2026-05-01 14:21  

#### 问题描述
在塔防模式游戏界面中，返回主菜单按钮的可见性和可访问性存在问题。当玩家进入关卡后，未开始波次前，返回按钮的选择器定位困难。

#### 复现步骤
1. 进入塔防模式
2. 选择任意主题和关卡
3. 进入游戏界面
4. 尝试点击返回菜单按钮
5. 观察到按钮定位问题

#### 预期结果
- 返回菜单按钮应始终可见且可点击
- 按钮应有明确的选择器ID

#### 实际结果
- `#back-to-menu` 按钮处于 `hidden` 状态
- 需要通过其他方式定位返回按钮

#### 建议修复
1. 检查游戏界面中返回按钮的正确选择器
2. 确保返回按钮在所有游戏状态下可见
3. 考虑添加统一的返回按钮ID
