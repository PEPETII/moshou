# 《墨守成规》按钮组件功能测试计划

## 1. 测试目标

验证游戏中所有按钮组件的功能完整性、交互响应和边界条件处理能力。

## 2. 测试范围

### 2.1 按钮类型

| 按钮类别 | 具体按钮 | 位置 |
|---------|---------|------|
| 主菜单按钮 | 图鉴、塔防模式、征服模式、自定义 | 主菜单 |
| 导航按钮 | 返回主菜单、返回主题、返回图鉴 | 各子界面 |
| 游戏功能按钮 | 开始波次、召唤、升级、出售 | 游戏界面 |
| 图鉴按钮 | 炮塔图鉴、怪物图鉴、融合图鉴 | 图鉴界面 |
| 模态框按钮 | 确定、取消、关闭 | 弹窗 |

### 2.2 测试场景

1. **正常点击操作测试** - 验证按钮基本功能
2. **边界条件测试** - 快速连续点击、长时间按住
3. **异常状态测试** - 禁用状态、加载状态
4. **交互功能测试** - 与其他模块的联动

## 3. 测试用例设计

### TC-BTN-001: 正常点击操作测试

| 步骤 | 操作 | 预期结果 |
|------|------|---------|
| 1 | 点击"塔防模式"按钮 | 进入主题选择界面 |
| 2 | 点击"征服模式"按钮 | 进入征服模式主题选择 |
| 3 | 点击"图鉴"按钮 | 进入图鉴主界面 |
| 4 | 点击返回按钮 | 正确返回上一级 |

### TC-BTN-002: 快速连续点击测试

| 步骤 | 操作 | 预期结果 |
|------|------|---------|
| 1 | 快速连续点击"开始波次"按钮5次 | 只触发一次波次开始 |
| 2 | 快速连续点击"召唤"按钮10次 | 按金币限制正确响应 |
| 3 | 快速切换点击不同炮塔选择按钮 | 正确切换选中状态 |

### TC-BTN-003: 长时间按住测试

| 步骤 | 操作 | 预期结果 |
|------|------|---------|
| 1 | 长按"召唤"按钮3秒 | 只触发一次召唤 |
| 2 | 长按炮塔选择按钮2秒 | 正确选中/取消选中 |
| 3 | 长按返回按钮2秒 | 正确返回 |

### TC-BTN-004: 禁用状态测试

| 步骤 | 操作 | 预期结果 |
|------|------|---------|
| 1 | 点击金币不足时的锁定炮塔 | 无响应，保持锁定状态 |
| 2 | 波次进行中点击"开始波次" | 按钮禁用，无响应 |
| 3 | 游戏结束时点击功能按钮 | 按钮禁用，无响应 |

### TC-BTN-005: 交互功能测试

| 步骤 | 操作 | 预期结果 |
|------|------|---------|
| 1 | 点击炮塔选择→点击画布放置 | 正确放置炮塔 |
| 2 | 点击融合预览→点击确认 | 正确执行融合 |
| 3 | 点击升级按钮（金币充足） | 正确升级炮塔 |
| 4 | 点击升级按钮（金币不足） | 按钮禁用或提示 |

## 4. 测试执行步骤

1. 启动游戏服务器
2. 使用 MCP Playwright 执行自动化测试
3. 记录每次点击的响应时间和结果
4. 截图记录异常行为
5. 生成测试报告
