# 玩法创新原型（可交互）

对应设计文档：[`../docs/玩法创新方案.md`](../docs/玩法创新方案.md)

## 这是什么

六个独立自包含的 HTML 原型，每个对应一条跳出传统塔防框架的玩法思路。**每个页面都是可点击操作的沙盘，不是静态效果图。**

直接用浏览器打开 `index.html` 即可，无需启动服务器、无需构建、无外部依赖。

## 目录

| 文件 | 方案 | 优先级 | 可交互内容 |
|---|---|---|---|
| `03-语法羁绊.html` | 三 | **P0** | 落字成词（偏正／动宾／并列）、三字成行触发句法技、悬停预览将生成的词 |
| `04-墨为血.html` | 四 | P1 | 落字／蘸墨修复笔画、观察干涸与晕染、看敌人擦掉笔画导致字降级 |
| `01-字格营造.html` | 一 | P1 | 选择结构后在格纸上落字，四种字形结构产生不同攻防效果 |
| `02-句读改径.html` | 二 | P2 | 点击字间空隙插入标点（、。？！），实时改变敌人在字行上的流向 |
| `05-对句波次.html` | 五 | P3 | 从候选字中选出下联并对句，看工整度如何影响这一波敌人 |
| `06-错别字入侵.html` | 六 | P3 | 看敌人用形近字改写你的塔，点击被改坏的字进行「校勘」 |

## 阅读建议

按 `index.html` 的卡片顺序（P0 → P3）阅读。每个页面顶部有一句话主张，中部是画布，底部两张卡片分别说明「与现有系统的关系」和「该方案的风险」。

## 重要说明

- **未改动任何游戏代码**：`index.html`、`js/`、`css/` 零改动，不影响 `npm test` 与平衡性基线。本目录不参与构建。
- **数值仅用于演示**：原型里的伤害、冷却、耗墨量都是为了让效果可见，不代表最终平衡数值。
- **视觉方向**：白纸底 + 墨黑字 + 朱砂红点缀，对齐游戏既有的水墨美术方向。
- **禁止事项**：遵守 `AGENTS.md`，未引入构建工具、TypeScript 或任何外部 CDN 资源，全部离线可用。
