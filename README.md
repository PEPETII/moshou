# 《墨守成规》

**一款以汉字和水墨表现的纯前端塔防游戏。**

玩家在关卡中布置不同职能的炮塔，抵御沿路径推进的敌人；也可以按已配置的配方融合炮塔，组合攻击、控制、防线与辅助效果。

## 游戏特色

- **汉字与水墨表现**：炮塔、敌人和战斗反馈使用汉字，搭配墨迹效果。
- **多种炮塔与配方融合**：炮塔类型、可用配方和进化关系持续以代码配置为准，不是任意两塔都能融合。
- **普通关卡与征服模式**：两种模式各有自己的关卡、波次和交互流程。
- **桌面与触屏操作**：包含鼠标、指针和触屏交互路径。
- **水墨主题音效**：用 Web Audio API 即时合成落笔、笔锋、墨散、印章、波鼓和纸裂短音效；两种模式均可开关，浏览器允许本地存储时会记住设置。
- **宣纸浅色界面**：以宣纸底色、浓淡墨色和朱砂色作为当前 UI 主色。

## 基本玩法

1. 选择普通关卡或征服模式中的主题与关卡。
2. 按炮塔类型将炮塔放在路径上或关卡指定的建造格。
3. 依据当前开放的融合配方组合炮塔，并调整防线应对敌人波次。
4. 管理墨水、炮塔和核心状态，完成关卡目标。

具体炮塔、敌人、关卡和融合规则以当前代码实现为准，README 不维护另一份数值清单。

## 快速开始

项目无需构建步骤。安装 Node.js 后，在仓库根目录启动静态服务器：

```bash
npx serve .
```

然后打开终端显示的本地地址。

## 技术与结构

- **运行方式**：HTML、CSS、Canvas 与普通 JavaScript 脚本；脚本按 `index.html` 中的顺序加载。
- **音效**：`js/audio.js` 使用 Web Audio API 程序化生成音效，无外部音频文件；需浏览器支持 Web Audio。
- **配置与数据**：炮塔、敌人和融合配置位于 `js/config*.js`；普通关卡数据位于 `js/data/levels/`，征服数据和逻辑位于 `js/conquest*.js` 与 `js/modes/conquest/`。
- **核心实现**：主入口和控制器位于 `js/`，细分职责位于 `js/core/`、`js/entities/`、`js/ui/`、`js/modes/`。
- **样式**：`css/` 下按页面、模式和界面职责拆分。
- **检查与测试**：`tests/` 存放自动化检查，`scripts/` 存放开发工具，命令由 `package.json` 提供。
