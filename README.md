> 在这个黑白的水墨世界里，"文字"就是你的武器。布置"火"炮塔，看它化为飞火流星；融合"火"与"山"，创造威力强大的"火山"阻挡敌人；筑起"山"字壁垒，阻挡"尸"潮的汹涌来袭。这不仅是一场策略的较量，更是一场文字与水墨的艺术。

## ✨ 游戏特写

- **水墨文字艺术风格**: 游戏中的一切——炮塔、敌人、地图、特效——全都由汉字构成，配以水墨渲染特效（墨晕、飞白、拖影）。
- **极简水墨画面**: 黑白灰为主色调，朱砂红点缀核心，营造浓郁的中国风意境。
- **六种基础炮塔**: 金、木、水、火、土、山，各具独特技能。
- **融合炮塔系统**: 任意两种炮塔可融合成强大的融合炮塔，获得组合技能！
- **动态文字特效**: 攻击、爆炸、减速、灼烧……所有效果都通过文字的动态变化来呈现。
- **六关挑战**: 从简单到复杂的关卡设计，难度递增。

## 🕹️ 玩法简介

1.  **布置防线**: 在敌人路径旁边的网格上，花费墨水放置你的文字炮塔。
2.  **炮塔融合**: 将任意两种炮塔拖拽到一起，花费墨水融合成更强大的融合炮塔！
3.  **迎击敌人**: 敌人会沿着固定的路线进攻，你的炮塔会自动攻击。
4.  **升级炮塔**: 击败敌人获得墨水，用来升级你的炮塔，让它们变得更强。
5.  **守护核心**: 别让敌人突破防线，抵达核心！

### 基础炮塔

| 名称 | 特性 | 解锁关卡 |
| :--: | :-- | :--: |
| **火** | 追踪攻击，单体伤害 | 第1关 |
| **水** | 范围减速50% | 第1关 |
| **山** | 路径阻挡，近战反伤 | 第1关 |
| **木** | 攻速极快，持续输出 | 第2关 |
| **金** | 直线穿透，贯穿打击 | 第3关 |
| **土** | 范围AOE伤害 | 第4关 |

### 融合炮塔系统

将两种不同的炮塔放置在相邻位置，选中后融合生成强大的融合炮塔：

| 融合组合 | 名称 | 特性 |
| :--: | :--: | :-- |
| 火 + 山 | **火山** | 发射火球并阻挡敌人 |
| 火 + 水 | **蒸** | 发射火球并减速，触发蒸发效果 |
| 火 + 木 | **炎** | 快速发射燃烧弹，造成持续灼烧 |
| 水 + 木 | **淋** | 连射减速弹，缓速效果叠加 |
| 金 + 火 | **钬** | 穿透攻击带灼烧效果 |
| 水 + 山 | **涧** | 阻挡敌人并减速周围 |

| 名称 | 特性 |

## 🚀 快速开始

本项目是纯前端项目，无需复杂编译。

1.  **下载项目**: `git clone https://your-repo-url.git`
2.  **启动服务**: 在项目根目录，使用任何静态文件服务器。推荐使用 `serve`。
    ```bash
    # 全局安装 serve (如果尚未安装)
    npm install -g serve

    # 启动服务
    serve
    ```
3.  **开始游戏**: 在浏览器中打开提示的本地地址 (通常是 `http://localhost:3000`)。

## 🛠️ 技术栈

- **核心**: HTML5 Canvas / CSS3 / JavaScript (ES6+)
- **渲染**: 自定义水墨渲染引擎（墨晕、飞白、拖影效果）
- **音频**: Web Audio API 音效系统
- **开发工具**: Visual Studio Code
- **版本控制**: Git

## 💡 核心系统

### 水墨渲染
- **墨晕**: 文字边缘的模糊扩散效果
- **飞白**: 文字的粗糙笔触效果
- **拖影**: 移动物体的墨迹残留
- **远山背景**: 关卡背景的层叠山峦

### 融合系统
游戏中可以将任意两种炮塔融合成强大的融合炮塔。融合需要：
1. 两种不同的基础炮塔相邻放置
2. 选中一个炮塔后点击另一个炮塔
3. 花费融合费用（两塔费用之和的折扣价）
