# 《墨守成规》

**一款以汉字和水墨表现的纯前端塔防游戏。**

玩家花墨布置「火」「水」「土」「木」四座字形塔，抵御沿路径源源不断涌来的敌人，坚守到限定时间；塔以笔画书写字形弹道，蓄满后自动释放大招。

## 游戏特色

- **汉字与水墨表现**：炮塔、敌人和战斗反馈使用汉字，搭配墨迹效果。
- **字形弹道**：当前启用火、水、土、木四座塔（其余单字塔已下架，代码保留）；融合与升级系统已删除。
- **普通关卡与征服模式**：两种模式各有自己的关卡、波次和交互流程。
- **桌面与触屏操作**：包含鼠标、指针和触屏交互路径。
- **水墨主题音效与背景音乐**：用 Web Audio API 即时合成，不使用音频文件。炮塔攻击音按系别区分（火、水冰、风木毒、金属、雷光、土暗），击杀音分小、大、首领三档，另有界面点击、出售、拒绝、胜利与失败音效。背景音乐为古筝、竹笛与波鼓的五声音阶合成曲，会随菜单、战斗准备、波次进行、结算以及五个主题与战斗强度变化。音效、音乐可分别开关并调节音量（设置页与战斗界面均可操作）；首次点击后才会出声，切后台自动暂停，浏览器允许本地存储时会记住设置。
- **宣纸浅色界面**：以宣纸底色、浓淡墨色和朱砂色作为当前 UI 主色。

## 基本玩法

1. 选择普通关卡或征服模式中的主题与关卡。
2. 按炮塔类型将炮塔放在路径上或关卡指定的建造格。
3. 开局前选择敌潮「稀 / 常 / 潮」，布塔、出售调整防线，用鼠标滚轮、键盘、拖拽或屏幕边缘滚动镜头。
4. 管理墨水、炮塔和核心状态，完成关卡目标。

具体炮塔、敌人和关卡以当前代码实现为准，README 不维护另一份数值清单。

## 快速开始

项目无需构建步骤。安装 Node.js 后，在仓库根目录启动静态服务器：

```bash
npx serve .
```

然后打开终端显示的本地地址。

## 技术与结构

- **运行方式**：HTML、CSS、Canvas 与普通 JavaScript 脚本；脚本按 `index.html` 中的顺序加载。
- **音频**：`js/audio.js`（核心与总线）、`js/audio-cues.js`（短音效）、`js/audio-bgm.js`（背景音乐引擎）、`js/audio-director.js`（场景导演与首次手势解锁）使用 Web Audio API 程序化生成声音，无外部音频文件；需浏览器支持 Web Audio。
- **配置与数据**：炮塔、敌人和字形弹道配置位于 `js/config*.js`；普通关卡数据位于 `js/data/levels/`，征服数据和逻辑位于 `js/conquest*.js` 与 `js/modes/conquest/`。
- **核心实现**：主入口和控制器位于 `js/`，细分职责位于 `js/core/`、`js/entities/`、`js/ui/`、`js/modes/`。
- **样式**：`css/` 下按页面、模式和界面职责拆分。
- **检查与测试**：`tests/` 存放自动化检查，`scripts/` 存放开发工具，命令由 `package.json` 提供。
